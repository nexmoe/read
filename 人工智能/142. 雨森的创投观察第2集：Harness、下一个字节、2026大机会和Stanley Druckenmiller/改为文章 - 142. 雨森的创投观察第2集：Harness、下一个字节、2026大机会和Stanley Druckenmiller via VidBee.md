## 说出去的话，会反过来绑住你

越强烈地表达一个观点，就越容易被自己说出的话限制。话如果是公开说的，限制只会更多。这也是我一度不想录第二期的原因。人很容易被自己的公开表态绑架：看空一条趋势，就容易空仓、不想买，哪怕后来事实变了，也不肯改口。

即刻上有人把这层窗户纸捅破了。意思是：如果你觉得观点被打脸，就不愿意再说，那你才是真正被自己的观点绑定了。你应该是一个持续学习、持续进化的人。后来我也这么跟别人说过，下一次干脆别录了，说出去的话会变成一种符咒。得到的回应是：不能被自己说过的一句话束缚；觉得被打脸就不录，那才是真的被打倒。

这其实就是费曼学习法。你不断表达、思考，再从外面拿反馈。它很像模型的强化学习，你需要一个反馈信号。生活里不一定有人会直接批评你，市场不会说好话。市场说你错了，你就是错了。听众把旧内容翻出来说“你看，是不是被打脸了”，对思维是一种练习。

## 过去八个月，模型之王换了好几轮

作为早期投资人，你必须在事情很早的时候思考，并给出判断。打脸是常态。陆续被打脸，很多时候只说明这个行业变得很快；变得快，就意味着机会多。AI 里被打脸的判断本来就特别多。

上次录的时候大约是十一月、十二月，大家最关注 OpenAI。当时它的 DAU 说是八个亿，很快要到十个亿。它宣布向谁买算力，比如和 Oracle 相关的消息一出来，股价可以立刻跳几十个点。到去年十二月，Gemini 3 发布，叙事变成：Google 有 TPU，有最多的算力，有很多人才，还有原生多模态，Google 要替代 OpenAI 成为模型之王。今年一月，大家发现 Claude 的 coding 很强，后面就是 Claude Code，几乎人人都去学着建一个 coding 工作流。大约三月，Claude 收入涨得非常快，二级市场二手估值一度超过 OpenAI，叙事是 Anthropic 一骑绝尘。限定到五月再看，Codex 也不错，新用户增速已经超过 Claude Code；中间还有一版模型被说成“有点降智”，后来发现是一连串系统问题；GPT-5.5 出来之后，大家又觉得 OpenAI 有卷土重来、你追我赶的意思。

**哪怕只问“现在哪个模型更好”，过去六到八个月里，不同时间会得到不同答案。** 一个人如果怕被打脸，就永远不说、永远不判断，那也永远不会被打脸。阶段性复盘，对我自己、对交流，都有帮助。

## 观点要强，但不要被它绑架

二级市场有句话，叫 **strong opinion, weakly held**：要有很强的观点，但不要被自己的观点绑架。有强看法时，最好知道这个看法是怎么来的，是因为一、二、三。原因变了，真正聪明的做法是改看法。说出去的话更难改，这是我要努力克服的事。

上次我有一个比较重要的判断：大家指望的 OpenAI 收入有落空风险。当时它的核心收入被分成三块，订阅、广告电商、企业服务。六个月后再看，前两块确实没有大家想的那么快。Pro 的付费，还有广告电商，进度都低于预期。但企业服务里的 coding 收入大幅增长，这是站在去年十一月底、十二月初看不到的。Claude 4.5、4.6 之后，出现了从量变到质变的提升，很多人以前用 AI coding 完成不了的任务，现在能完成得很好。变化发生之后，对未来轨迹的判断自然也要变。世界本质上是贝叶斯的，前面发生的事会影响后面的概率。

所以我对整体回报的时间线是往后推的，自己的仓位和投资也会调整。这就是 AI 的魅力：经常发生很大的变化，每天都有新鲜事，也充满好奇心。

有人专门翻了上次的说法，指出我当时说的是**今年下半年迎来回调**。上半年不但没有回调，反而更疯狂。这个判断我不再死扛。

## 二级仓位：加回去了，但没有朋友那么猛

我在二级市场的偶像是斯坦利·德鲁肯米勒，当年索罗斯身边的操盘手，现在做自己的基金。他是交易员，不是拿着一只股票放五年的基本面投资人。我自己的二级风格也更偏交易。

看到 coding 用量大幅上涨，自己也频繁用 Claude Code，给自己做了不少小工具之后，我确实觉得这是一个影响很深远的变化。硅谷里，Meta、Google 越来越多的公司在全民试水，一起用 coding agent，用很多 token 试创新。身边的朋友体感也很强，有人一个月烧掉几千甚至上万美金的 token。这会继续带动 token 消耗，所以我加回了一些仓位，包括大家耳熟能详的存储、光、CPU，这些所谓“卡脖子”的长尾。硅谷现在的大方向是做多硬件，尤其做多硬件里的瓶颈。

但加仓没有朋友那么激进。今年确实有非常多朋友赚了很多钱。我受到的限制，与其说是观点本身，不如说是那次公开表达：话说出去、产生了影响力，就会限制你。公开表达得越强烈，限制越多。

## 看对的，是对 C 端的担心

看对的部分，主要是当时对 Return 的担忧，而且主要是对 C 端。

第一，以 OpenAI 为代表的普通用户订阅，比较难提价。用户付 20 美金一个月的时候，很难很快提到几十、一百美金。第二，当时已经有大约五千万付费用户，比较愿意为日常 chatbot 付费的人，很大程度已经被筛出来了，再往上提很难。它的 DAU、付费用户增速、每个付费用户的 ARPU，我认为都会比较慢。过去六个月，这块增长确实陷入了某种停滞。

第二块是广告和电商。当时 OpenAI 很努力，招了很多人，推了很多新产品形态。我认为，在一个很创新的用户产品里做广告、做电商，不是把广告塞进去就行。字节这么强的公司，抖音和 TikTok 里的电商、广告也探索了很久。Facebook 和 Google 成立之后，都花了六到八年，才变成广告超级引擎。大家当时对在 ChatGPT 里插广告太乐观了，它不会那么简单。这一点也得到了验证。

就当时 ChatGPT 作为最受关注的那个渠道而言，这两个判断没有大问题。

## 看错的，是 coding 会这么快过阈值

完全没预料到的，是 coding 会在这么短的时间里发生这么大的变化。

如果对象是智力，它很多时候是突变，和互联网很不一样。上个世纪末，电商、广告、门户、即时通讯这些商业模式的底子已经出现了。互联网要做的是把更多人连起来、把网速做快、把变现效率做高，模式出现得很早，后面是不断完善。AI 本质上是智力。把一只猫的智力提高到智商八十、九十，是很大的成就；但你招员工，至少希望对方智商有一百。**没过阈值之前，价值出不来；过了阈值，价值会突然出现。**

这很像蒸汽机。水要烧开才有蒸汽。烧到九十九度，不会有蒸汽机。到底多少度才算烧开，提前很难估。各方面的信息，包括更早和 Anthropic 相关的访谈，大家对 coding 什么时候越过阈值、agent 什么时候真能跑起来、什么时候能完成高价值的 coding 应用，并没有一个明确预期。否则 Claude 4.5 可能就不叫 4.5，而叫 5。版本号本身也说明，他们当时没有那么大的期待。

事后看，并没有范式变化，没有新的模型架构，也没有一种全新的训练方式。就是从 4 到 4.5，再被 4.6 进一步放大，编程体验发生了本质变化。背后大家普遍觉得数据占了很大一部分：高质量的用户指令，让模型的编程更好；同时也有很多 agent 和工具使用的部分。原来跑不起来的 agent 流程跑起来了，AI 开始能做更长时间、更高价值的编程。这个节点什么时候到，事先不知道；事后看，却相当明显。

我也不敢说自己“理解”了 Anthropic。它对中国相对封闭，我们很多信息是二手的，不是一手的。有些人一定比我更理解。我只能说，今年三月在硅谷转了一圈，大家普遍提到的一点是组织能力和组织形态。

ChatGPT 出现之前，没人知道 AI 能做什么。那是一个自下而上、靠超级个体灵光一现的探索阶段。OpenAI 相对松散、自下而上的结构，适合探索不同方向。它最早有三个方向：机器人、世界模型、打游戏，语言模型当时只是一个小团队。探索期，支持自由探索很有价值。

现在 AI 进入主线逐渐收敛的阶段。Anthropic 重仓 coding，我的理解不是它一上来就喊“我就要做 coding”，而是训练数据里 code 的比例越来越多，code 表现越来越好，同时它选了一条做 enterprise、做生产力的路，和 OpenAI 做大 C 端不太一样。方向比较明确之后，它体现的是自上而下的组织能力。每个人进去都有价值观面试，这是对共同方向的认可。它也不那么强调个人英雄主义。

OpenAI 有很多明星研究员，每个人可能都有自己要做的方向。你是明星，我也是明星，各自有想法，资源分配就会别扭。对 Sam 的一种评价是，他有点像以前当 YC president 时的那个角色，像个天使投资人，不断鼓励各种小项目。于是经常看到东西做出来、上线，后来没人管，又消失了。GPTs、Sora 已经算比较大的尝试，浏览器做了，现在不知道还有谁在用，operator 也是很多新尝试。它缺的是持续性，因为很多是很小的团队自下而上做的，有点**管杀不管埋**。

Anthropic 不只是招人的价值观和公司方向一致。Dario 大约每两个星期会在内部同步一份自己的思考 memo，组织是对齐的。这点有点像一些战斗力很强的中国公司。产品迭代也快。三月份，Claude Code 几十天里迭代了几十个功能，桌面端经常一打开就又升级了。它是**管杀也管埋**的组织。

所以，探索期适合自下而上、发散的组织；高速赛跑期，适合一开始就明确 bet、自上而下、价值观和方向比较齐的组织。这是这个阶段的组织优势。OpenAI 仍然有很多创新的种子在萌芽。如果接下来几年范式不怎么变，这种更专一的优势会很大；如果一两年后下一个范式诞生，可能会重新回到探索阶段。

这就是我去年说的第二个 R，Research。当时硅谷有很多 New Lab，大家在 bet 的是：下一个范式可能又需要这种更发散、更自由、同时资金很多的组织。结果现有范式下，coding 先发生了一次大的落地转变。这是很多人没看到的变化。

还有一个观察。去年以前，很多人把 coding 当成垂直领域，和医疗、金融并列。即便我和不少人早就觉得 coding 是比较通用的能力，跟一些自己不做 coding 的研究员聊，他们往往也觉得它只是垂直方向之一。现在看，**coding 不是垂直的，它是水平的，是 horizontal**。它可以加强办公室工作，加强医疗，加快研究。这让 coding 的意义完全不一样。做出来之后很显然，做出来之前并不显然。

## 卖 API 不够，Harness 把公司做成了另一种样子

大家之前担心 Anthropic 是不是一家卖 API 的公司。Claude Code 还没这么风靡的时候，姚顺宇也这么认为。他去年年中的担心是：你在卖 API，别人的 Codex 卖得更便宜，你是不是就不够好。当时怕的是，更好或更便宜的模型一出来，卖 API 就没有门槛和壁垒。

没有 Claude Code，只卖 API，Anthropic 会是一家很不一样的公司。Claude Code 带来大量高质量使用数据。各方面了解到，这些数据回流确实能训练更好的 code 模型，形成数据飞轮。最近 Codex 涨得也很猛。Claude Code 和 Codex 都是 harness。不是你有了强大的模型、把 API 卖出去，就自动有很强的优势。用户用的是产品，不是直接用 API。它既有好模型，又率先做出了一个能做 long time horizon 任务的 harness。这是这家公司做对的事。

好的 harness 是不是未来都得模型公司来做？我觉得不一定。Claude Code 可以接别的模型，和模型的耦合没有那么强。年初 OpenClaw 是个人做的，一度成为非常火的 harness 之一。至少不是只有模型公司才能做出第一方的好 harness。模型公司当然有优势，你知道自己的模型往哪走，知道参数和细节，自己的 harness 会做得不错。但 OpenClaw 里很多创新，未必只有模型公司想得出来。

现在几个好的 harness，有些是公司自己做的。OpenAI 的一些产品和 Manus，以前也是 harness，只是去年大家都说这是套壳、不重要，现在改口叫 harness、变得很重要。对一件事重不重要的判断，本身就在变。

## 三个月看被低估，一两年看可能被高估，十年再另说

Anthropic 的优势稳不稳，今天是被高估还是 OpenAI 被低估，要分短期、中期、长期。

很短期，比如三个月，可能两边都被低估。假设他们今天上市，普遍认为至少是两万亿美元的公司。现在 Anthropic 老股大约九千亿美元，OpenAI 也差不多这个量级，而它们预计在下半年或明年上市。以现在的市场情绪，上市直接翻倍、炒到三万亿，都有可能。按大家预期，年底 ARR 大约一千亿美元，对应现在大约一万亿的估值，大约十倍，不能说特别贵。只从很短期的市场情绪看，Anthropic 和 OpenAI 反而都可能被低估。

从一两年看，我仍然认为它们可能被高估。Return 的问题没有真正解决，只是换成了另一种形式。两年后再看，估值有可能大幅下降。

从十年看，赢家也许是一个，也许两个都在，也可能都是五万亿、十万亿的公司。

还有一个看法：现在头部几家模型公司没有拉开真正大的差距。谁最后发模型，谁就显得最厉害，因为每一代都是比较大的提升，后发有后发优势。用这个去过度推演，也会出问题。

## Claude Code 和 Codex：好马配好鞍，然后变成渠道战

很多人会有品牌锁定。我自己用 Claude Code 用得挺好，就未必有动力去试 Codex。先发的品牌心智、用户粘性都很重要。粘性有的来自习惯：我在 Claude Code 里配了很多 skill，很多配置写在 CLAUDE.md 里，换到 Codex 得重新弄一遍。

Codex 现在有点价格战，同样的用量合下来，成本大概比 Claude Code 便宜百分之五十。一些两边都用的朋友也反映，它在 long horizon、在 reasoning 上其实挺好。一个人如果一上来就用 Codex，可能也会觉得挺好。两边做很多任务已经没有那么本质的差别时，就变成品牌、渠道和价格的竞争。

两个月前问我，Codex 还落后 Claude Code 挺多。GPT-5.5 改变了很多人的认知。有点像好马配好鞍。现在模型和 harness 常常通过 coding plan 绑在一起，你得分清优势来自折扣价的模型，还是 harness 本身。整体看，五月中旬的差别，已经没有两个月前那么大。

## 回报是一条链：投入、产出、结果

我们投入这些 capex，最后要变成回报，这是问题的本质。Anthropic 收入大涨，让很多人认为回报问题已经解决。我的看法是：**那不是最后的回报，那是它客户的投入。** 大家买这么多 token，不是烧着玩，是想要结果。回报问题被下推到了 Anthropic 的客户这边。

客户买的、烧的 token，需要得到的是做出来的软件，这是产出。光有软件还不行，软件要卖钱，或者要能降本，带来利润提升，那才是结果。可以看成三步：**投入、产出、结果。** 现在大家在拼命投入，因为觉得投入最后有结果。利润的增加，要么收入增加，要么成本减少，也就是降本或增效，或者两件一起。

如果这个循环成立，就要看到终端用户最后有新的利润。从增效看，增加的收入应该来自新产品、新服务、新的业务领域。移动互联网过去几年其实停滞了，大家觉得没有什么新的产品形态。原因是缺程序员写功能，还是缺好的产品经理去发现需求？很多时候不是缺人写代码，而是不知道该做什么。

再做一个思想实验：一家稍微有点规模的公司，突然多了十倍工程师，收入会不会大涨？很多时候不会。经常有人反馈，用了 agent coding，个人产出和效率提升了十倍。十倍此起彼伏，公司是不是多出很多新产品，卖给很多新用户，带来很多新收入？目前没有观察到最后结果的大幅度提升。

会不会只是时间还没到，又是那个烧开水的问题？我认为新产品、新功能是逐渐出现的。不是程序员突然多了十倍，新功能就突然多出来。token 是现在就烧掉的，建设和回报之间会有时间错配。以前建 GPU 集群、算力中心，大家想的是接下来六年甚至更长时间把钱赚回来。今天烧掉的 token，能不能过两年再赚回来？能忍耐的时间可能比大家想的更短。

美股和中国都有一个现象：硅谷原来没那么内卷，一个重要原因是程序员很贵。程序员这么贵，最好让他做核心业务。现在突然有了很多便宜的编程能力，又不知道该做什么新东西，有的公司就开始互相卷、进入彼此的领地。原来 Lovable 做网站，现在也能做 PPT；原来 Gamma 做 PPT，现在也能做网站。能用 agent coding 之后，不知道做什么新的，第一反应是把别人的功能做一遍。复制一个已有功能越来越快；做出一个大家都没想到的功能仍然很难，因为那不是编程问题，是创新问题，是产品问题。

**增加编程能力，不会立刻增加收入。** 所以现在大家发现，降本才是眼前的核心，说到底就是裁员。token 烧了这么多，人员工资不减少，总成本是上升的。

裁员这件事，我有三层看法。

第一，如果出现大规模裁员，这些程序员的收入也是别人公司的收入，对整个经济影响巨大。硅谷我的感觉是，几乎每个人都实实在在担心被裁，因为工作的主要部分——编程——已经能被 AI 做得很好。但一个程序员百分之八九十的工作是编程，还有百分之一二十是沟通、协调、管理，是人和人之间的信任。这部分时间可能不多，却不能被 agent 直接取代。替代他的编程容易，替代他在组织里的关系、信任和交流不容易，人不能简单裁掉。硅谷大公司当然有一部分本来就招多了，AI 来不来都可以裁。裁掉百分之十五，很多时候是裁冗余。再往里裁，没有那么简单。这有点像自动驾驶：很早就能解决百分之八十甚至九十的高速公路驾驶，但还不能直接把人去掉，因为还有 corner case。软件工程师的工作里，也还有一些 corner case。

第二，人在组织里能背的锅有限。只要 AI 还不能端到端完成一项工作，它就算多写十倍、一百倍报告，人还是要对报告驱动的行为负责。

第三，裁员只能做一次。一个人只能裁一次，省下来的是一次性投入，不能持续地、增量地省出更多成本。

所以 return 问题没有真正消除，它是以 Anthropic 收入的形式被盖住了。只要 Anthropic 有收入，上游的硬件、内存、光模块就有很多订单。可如果它的客户最后没赚到钱，还会不会继续买这么短周期的 coding token？这非常值得观察，要打一个问号。

现在涌进来用 AI coding 的人，远多于发现自己烧的 token 没那么多价值的人。有点像一个水槽：上面有无数想吃螃蟹的人，下面有人觉得螃蟹不好吃、离开了，但进来的远多于离开的。所以 Anthropic 和 OpenAI 的 ARR 涨得非常快，国产模型只要有算力也卖得动、收入涨得快。最后还是得把漏水堵住。来尝鲜的人要能从中赚钱，而且赚钱周期不能太长。今天烧 token，过两年才赚钱，大部分公司受不了。

我们自己也做了很多 AI coding 的尝试。二、三月估计都养了不少“小龙虾”，烧了不少 token。很可能三月烧的比现在多很多，因为很多 token 没有带来本质价值。公司里这也是常态。

对小公司和个人，我确实觉得机会很大。原来个人和小公司的创新，很多时候卡在程序员不够：有想法，没人做。供应链因此会有很大变化。很多大公司的问题不是没人做，而是不知道做什么，以及组织效率很低。

## 不只有程序员：报告可以多十倍，责任不能

Coding 是泛化的，不该只拿程序员做比喻。下一步大家想到的是整个 office worker、知识工作者。比如报告能写得更多：原来要自己写，现在 AI 帮你写，那你是不是可以下岗？

做投资就是一个例子。每个人能看的报告都多了很多，投资决策最后还是要人负责。原来看一家公司，现在可以看十家，能承担的投资职责是不是就可以多投十倍的钱？我认为不是。一个组织里能背的锅是有限的。AI 可以多写十倍、一百倍报告，人还是要对结果负责。我投了这家公司，还是我对我的决策负责，AI 没法负责，我也没法开除它、关掉它。一个人能承担的职责是一定的，取决于他的工资，或者他能承担的损失。AI 没法替你担责。

只是把报告写得更好、模型做得更好，短期内不会让一个人多投十倍的钱、多承担十倍的责任。除非一份报告拿来就可以不看、肯定是对的，可以直接拿去指导行动。现在还有一定幻觉，很多工作还要人检查，瓶颈又回到人身上。检查时间可能变少，但生产端的提升，不等于结果端的结果。

回到那三步：投入端在大幅进行，产出多了一些，产出还没带来结果。这需要时间验证。

那现在看 return，会不会太早？肯定比较早。之所以现在要看，去年底就要看，是因为这个数太大了。如果只有几百亿美元，大家可能觉得花得起。现在整个 AI 今年在硬件上的投入是七千亿美元这个量级。最近都在说三星、海力士的工人一年有几百万元奖金，因为它们的利润已经接近英伟达。传统意义上的 CSP、几个大云厂商，利润已经低于存储厂商。硬件端的投入非常大。

与此同时，如果 Anthropic 按大家预期到年底做到大约一千亿美元 ARR，意味着每个月卖出大约一百亿美元的 token。掏这一百亿去买 token 的人，赚了多少钱？这个问题越来越需要在比较快的时间里回答，否则数字大到没法忽视，too big to ignore。

现在的 hyperscaler，比如亚马逊这些，已经在举债建数据中心。资金杠杆加上之后，对回报的时间要求其实在变短。

## 我们一直押的主线，其实没变

去年底说的是 Year of Return。当时也有人说 2026 会是应用爆发，有人说会是大厂 show up 之战。转过年来，和大家想的都不一样。

我们关注 AI 革命的主线一直比较清楚：看好 AI 对生产力的巨大提升，也一直认为只有 agent 才是 AI 提高生产力的主要形式。AI 不占用你的注意力，才能解放你的注意力。

从 2023 年到现在陆陆续续录过一些内容。2023 年的标题大概是“大模型只是起点”，人类未来会和多智能体紧密协作。2024 年很多人质疑大模型的商业价值，我当时说的是，模型能力的提升才能解锁更多 AI 的价值，尤其是编程、计算机使用、思考这三项，能在 2025 年解锁，让那一年成为 agent 元年。基于这个想法，我们较早投了 Manus、Genspark 这种第一波 harness 公司，也投了 Kimi。它应该是国内最关注 agent 构建的基础模型公司之一，2025 年完成了很大的转型，现在我们认为它可能是全世界最好的开源 coding 模型之一。

2025 年我的总结是，模型能力越来越强之后，我们将不再需要那么多 attention。以前人类做所有工作，写代码、做 PPT、干任何事，都需要人的注意力。AI 不能解放注意力，就没法带来本质提高。现在很多人睡觉前把任务布置下去，醒来发现 agent 把它做完了。这是模型能力提升带来的 agent 真正到来，于是一个人可以干很多事。

去年还有一集，说 agent 出现意味着每个人都可以当 AI 的老板。今年很多人确实经历过一种用 agent 上瘾的阶段，总觉得有做不完的事，一会儿让它做这个，一会儿做那个。有个朋友说得特别对：很多人是在享受当老板的快感。我当了很多年老板，比较懂那种言出法随。现在每个人都要当老板。

所以 agent 落地并不意外。我们一直看好 AI 对生产力的提升，一直看好 agent 这种形式，也一直在投这样的公司。以前大家说这是套壳、没有壁垒；现在说 harness 很重要，要有 harness engineer。2026 的 AI 世界，就是模型能力提升带来 agent 真正落地，而落地形态是在应用、在 harness 这样的产品上。

## Harness：像给 F1 车手配一整支维修队

以前用一个产品，不管是不是 AI 产品，有点像自己开车。现在更像 F1：车手在开车，车手变成了模型，开得很好，但你要有一堆人给它保养、换胎，让它待在赛道里。Harness 这个词来自马具，说的就是你怎么让一个非常强的东西，在你规定的范围里跑。

最底层是模型，大家讨论得最多：你有没有一个好模型。模型首先需要 context，因为有很多事它不知道，你得把 context 给它。可能是实时的，也可能是你这个组织专有的信息。实时很重要。Context 外面，还要给它工具，给它能跑任务的 agent 循环，让它在一个好的 harness 里做更多事。

OpenClaw 当时让人惊艳，是因为它给了模型很多权限，解锁了原来没想到的场景，比如直接在 Mac 的文件上操作。它还有一个心跳，heartbeat，大约每三十分钟让模型检查一遍有没有没做的事。机制讲出来都很简单，却让模型在更长的任务上完成得更好。这是 harness 外面的一层。

再外面，很多人在做 runtime。模型要用更复杂的应用。最早去年 Manus 出来时就做了 sandbox，当时和 E2B 合作，让模型在沙盒里上网、使用软件。现在大家越来越发现，需要一个持久的 sandbox，要给 AI 配一台更持久的电脑。DigitalOcean 这类机器最近也涨了很多。AI 能持久地待在一台电脑里跑更多任务，这件事变得很重要。

这些都架构在模型层外面。Harness 这一层，模型厂商自己在做，OpenClaw、Hermes、Manus、Genspark 这些也在做。Context 要用户通过产品给它，不会自己从天上掉下来。Runtime 也有很多公司在做。我们在模型外面包了越来越多的层，有的是模型厂商做的，有的是第三方创业公司做的。一个系统越来越多的价值，在模型外面包的这几层壳里。

壳变得更有价值，我是认可的。同时也还认可“模型即产品”。杨植麟非常坚定的那个观点，核心是说产品的核心能力由模型提供。我们现在打交道的，显然不是一个孤零零的模型，也不是把一个 API 丢给你就结束。API 你当然能接起来，但我们交互的始终是产品。

AI 这波浪潮的引爆者是 ChatGPT，ChatGPT 也是产品。它把 InstructGPT 这样的模型，串成对话，用 chatbot 的形式呈现。如果没有这个 harness，只让用户自己去跟模型 API 互动，不会有这么大的变化。你可以说 ChatGPT 是模型级产品，主要是模型外面包了一层 harness；没有这层，就没有那样的使用，也没有那样的革命。这两句话不矛盾。

进入 2026，有人觉得 harness 更重要，有人觉得模型就是一切、模型吞噬一切。这两个观点可以同时存在。拥有先进模型这件事，变得前所未有地重要。模型不够强，任务就完成不了。从早期投资人的角度看，模型生态会相对稳定，再出来一家现在这种头部公司，要的钱和难度都大很多。但同时，大家都在不同的 harness 上用模型。今年大家还意识到：**好的 harness 收集的数据，可以反哺模型。**

Anthropic 的 code 模型这么好，很大程度是 Claude Code 上面的数据闭环、数据飞轮、数据回传。以前大家觉得 chatbot 没有数据飞轮，是因为 chatbot 主要考验模型对世界的理解和智能，人类跟它聊的东西，很难让它变得更聪明，它已经训练过人类的大量数据。Coding 不一样，每个任务都在解决现实问题。你起一个项目，什么地方做好了，什么没做好，该用哪个库，哪个东西要变，这些都是高质量反馈。**拥有自己的 harness，比原来更重要。**

Cursor 就是例子。大家原来觉得做一个壳没什么价值。它证明了，composer 基于自己的 post-training，加上大量高质量反馈数据，可以训练出一个挺好的模型。哪怕只有壳，壳带来的数据加上 post-training，也能做出模型级产品。这句话也可能没说错，因为 composer 也可以说是它的产品。但这个模型从哪来？没有那个壳，就没有这个模型。

所以两句话同时成立：你仍然非常需要一个自己的好模型；同时，没有一个好产品，你可能就不会有这样独特的模型。

从外面看，这些壳最后好像都卖给了模型公司。从早期投资的角度，卖了也可以退出。AI 是一个很难看中局的行业。“壳没有价值”也许放到十年的终局里是对的，但不妨碍中间有好产品、好公司，甚至好的退出。谈太远，对实际的投资或创业不一定有意义。

互联网也一样。你可以说雅虎不本质，最本质的是搜索引擎，所以 Google 最好。但如果你是雅虎的天使投资人，那也是传奇。对早期投资来说，不会太拘泥于你是壳还是模型、到底要做什么。Cursor 最后也在做自己的模型。对用户来说，他们对 harness 更加忠诚。

很多朋友都有不断抢救自己“小龙虾”的过程。它功能很强，也有很多问题，老是死掉。包括我自己，经常要用 Claude Code 去把它救活。为什么要救？大家在意的是这个 harness 里存进去的 memory。至于模型，很多人是在小龙虾里面换着用的。Kimi K2.5 出来之后，有人发现小龙虾跑得很好，就把 Opus 或 Claude 换成 Kimi，觉得这是九十分的表现、二十分的价格。为了挽救记忆，要把 harness 救活；为了降低成本，可以换模型供应商。对终端用户，harness 更有粘性。

## 一个说框架重要，一个说模型重要，其实不矛盾

前两期里，福利和姚顺宇的看法差很多。福利觉得 OpenClaw 这种智能体框架非常重要，能激发中层模型的上限。姚顺宇觉得这种形态不太重要，更关注模型公司的能力。

我觉得他们不矛盾。两个人都是搞模型的，你问他们什么最重要，他们一定会说训一个好模型最重要。福利是聊到 OpenClaw 才有那个看法，他不会觉得 harness 比模型更重要。一个好的 harness，对提升模型表现、获取高价值用户的交互数据、形成数据回流，两边应该都认为重要。姚顺宇担心过一家只卖 API 的 Anthropic 壁垒不够，也就是只有 model 不够。福利说框架能提升中层模型的上限。这是他们共同的部分：好的 harness，对用好模型和训好模型都有很大帮助。

模型公司做 harness 是不是就能做到最好？我认为不一定。优势在于它了解模型的发展路线和结构，也有创意和很多聪明人。另一面，模型公司强调 researcher，做应用的公司对应用的理解，可能是两种能力。

OpenAI 以前有很多基于模型的产品雏形。Manus 出来的时候，它做 PPT 做得挺好。我问过一个在 OpenAI 做 agent 的研究员：这个 PPT 好像比你们做的也好看。他回答：这个不本质。对一个模型研究员，PPT 好不好看确实不本质；对用户很本质。用户用你做 PPT，就要好看的 PPT。模型公司说的“不本质”，是现阶段不以这个为目标去优化；它提高的是智能上限，能力本身上去之后，自然能做出好看的 PPT。这是相辅相成的。你永远可以说模型公司未来会做得更好，但未来那个更好的模型，一样能被 harness 拿去用，做出更好的产品。

对好的 harness 来说，比如 OpenClaw，它是希望模型公司升级模型的。它希望有更好的模型，让自己的 harness 把模型跑得更好，做更多事。逻辑不是“你一升级我就没饭吃”。

Claude Code、Codex 是第一方的，Manus、OpenClaw、Hermes 是第三方的，都有自己的特点。不能说 Claude Code 就完全覆盖、吊打开 OpenClaw。OpenClaw 部署在本地，给了更多权限，加上心跳等一系列机制，有它做得更好的地方。Claude Code 会进步，下一个像 OpenClaw 这样的产品也会进步。

用操作系统做比方：微软做了 IE 和 Office，早期这就是 Windows 上最重要的应用。但 Windows 上不只有微软的应用，还有 Adobe，还有 AutoDesk 各种各样的软件公司。我不认为最后的应用和 harness 都会是某一家自己做完。如果那样，生态和 use case 就太窄了。

## 几种壳，创新其实不在同一个地方

从我自己作为 VC 的体验说。

Manus 当时做了很多别人没做的事。它在 sandbox 里跑虚拟浏览器，让 AI 访问网页、执行操作。它很早做了 wide research。当时有个叫 deep research 的东西，我们开玩笑说这个是 wide research。它其实就是现在的 agent team、agent swarm：同时拉起十个、几十个 sub agent，执行不同任务。这比 Claude Code、比现在大家做 agent 团队都更早。后来了解到，Anthropic 做 Claude Code 时，也借鉴了 Manus 做 wide research 的经验。它做了很多引领的工作。一个做应用的、做 harness 的公司，把模型的 agent loop 和 context engineering 吃得很透，做出了模型公司没做出来的体验。这是创新。

Claude Code 的 CLI 是非常重要的展现形式。Terminal 里更便于 AI 操作，而不是在给人用的图形界面里操作。它通过 skill 这套对 agentic loop 的配置，把模型能力发挥得很好，让程序员获得了非常好的体验。

OpenClaw 的创新也很多。它跑在你的 Mac 上，可以访问里面的文件、日历、信息，这是原来一类云端产品不具备的。心跳让它能做定时任务，记忆更强。它的 memory 机制很有意思。ChatGPT、Manus、Claude 之前，大家都想把 chat 分开，不想串 context，这个 session 就是这个 session 的，那个就是那个的。OpenClaw 把所有东西放在一个大的聊天里，通过每天整理 memory 来实现记忆。很多研究员一开始不以为然，觉得 context 会串，AI 会幻觉。对用户来说，感觉非常强烈：它记得我。因为东西都丢进一个 context 了。后来大家纷纷跟进，Manus 也做了自己的。一个流式对话，是用户最简单、最朴素的沟通形式。

OpenClaw 有自己的 TUI，基本没人用。它是把 agent 插进每个用户最熟悉的地方，插进微信、WhatsApp、Discord。以前大家都想造自己的网站、自己的 App。它做的是：我去你熟悉的地方。这是它风靡的重要原因，尤其在中国，因为它能插进 IM。我们对 IM 最熟。

这些创新，显然不是一个典型的、只追研究本质的模型公司会先去做的。有的产品会被模型公司吸收进去，但很多时候那是产品设计理念。Context 目前就存在产品这一层。你当然可以把 memory 导出来，以后也许能训进模型。归根到底，你的 context 在什么地方？目前来看，在 harness 里面。

它们引领了产品创新，然后卖给模型公司，模型公司吸收产品能力，于是有人说能力最后还是在模型公司。那要看怎么卖。如果按这个逻辑，卖给微软，也并不是卖给“别人”就结束了。

我现在觉得，harness 本身更像操作系统，模型更像驱动这个系统的处理器。已经有应用是基于 Claude Code 或 Codex 的 runtime 再做一层，比如一个 skill 可以插进你的环境。我们看到的 Pencil，还有我们投的 Slock，都是基于你正在跑的一个 Claude Code 实例，再继续做功能。有点像在 Windows 上做一个应用。应用不用自己处理跟模型怎么通信，由中央这个 harness 处理；做 skill 的人只用考虑 skill 怎么做。

早期没有 Windows 的时候，写一个应用得自己处理怎么跟 CPU 通信，要写很底层的代码。DOS、Windows 这样的操作系统出现之后，你只处理跟操作系统的关系，CPU、内存、I/O 由操作系统调度。iOS 也一样，写一个移动 App，不用太考虑怎么跟苹果的处理器、摄像头通信，封装成接口，调用就行。

三年前，一个 AI 应用开发者得自己写 agent loop，自己处理 memory，自己处理模型这层 harness，做一个应用更辛苦。现在在 Claude Code 或这些 harness 上再做 skill、再做一个壳，这些不用自己处理，harness 帮你跑。Harness 变成操作系统层，模型变成处理器层。Windows 年代你可以用 Intel，也可以用 AMD，哪个价廉物美、哪个更强就插哪个。现在用户也可以给自己的 harness 插拔模型，再在这个“操作系统”上长出不同能力。

已经有一些趋势：有人在 Claude Code 上面做应用。对很多人来说 Claude Code 是 CLI，活在 Terminal 里，所以他们并不打开 Terminal 直接交互，而是用一个图形界面，跑在 Claude Code 这层上面。这是今年很有意思的趋势。

## 变化很快的时候，最怕为了稳妥去跟风

看创业者，有的人比较求稳，做一个大家已经讲了很多的概念，比如“我也做个小龙虾，稍微改一改”。变化很快、机会很多的时候，最怕的就是为了稳妥去跟风。东西不够创新，跟着别人跑，时间就浪费了。缺钱可以融资，一次创新失败可以再来。一上来做的事就不创新，在 AI 里很危险。

第一，要做真正大幅度的创新。第二，要敢于做 horizontal 的东西。硅谷很多人张口就是“我要做垂直，做得很垂直”。有人觉得垂直行业比较保险，大厂先不会来竞争，好像有一块小天地。技术发展早期变化太快，做得太垂直，容易把自己困住。你要是做对了一个更通用的东西，能力是可以发散的。有的产品刚开始做的时候，并不知道后来做 PPT、做网站会变成主要场景。它做的是一个比较通用的类型，后来才衍生出 PPT、网站、数据分析。技术变得很快的时候，horizontal 能让新浪潮对你有用，因为你最早发现一些新的市场，你是一个能承载不同场景的载体。

硅谷爱讲垂直，是 SaaS 的叙事，很多人被这个影响。通用机会已经被做得差不多了，才要去做垂直，去做一个宠物医院预约系统。技术早期还有 horizontal 机会时，勇敢去做通用、去做创新，才有大机会。这有点反共识，因为讲垂直的人非常多。

看跑出来的这些：Perplexity、Manus、Genspark、OpenClaw、Hermes，还有 Lovable。现在还很早，很多是后浪。Lovable 原来大家用它做网站，现在也在做各种平行扩张。机会发生的时候，就是要创新，而且要敢于做通用的东西。

今年所有人都要做 agentic coding，会不会过于同质化？肯定有一点。我还有一个暴论：我们对 AGI 一直在缩水。最开始的 AGI 是毁灭人类、是 singularity，后来变成解开黎曼猜想、创造新东西，现在变成替代普通程序员。有人说现在 AGI 已经实现了，我不太认同。那说的是 coding。把 AGI 说成这件事，是把标准说水了。

怎么样真正实现创新，仍然非常重要。写代码，尤其大部分日常写代码，是完全 within distribution 的事，写的都在人类已有代码里面。所以大家发现 AI 写前端最简单，因为前端做完就是那些东西。真正的 OOD 问题，现在仍是开放问题。

原来想的是要有新的生产力，也就是降本增效。降本正在发生。**现在 AI 毁灭旧价值的速度，远高于创造新价值的速度。** 创造新价值，是新产品、新药物、新发现，这些还得一步步做。美国新一代 lab 很多在做 auto research，用 AI 加速研究。姚顺宇也聊过，头部 lab 已经在用 AI 加速整个模型训练。大家都在做，已经能看到一些从 0 到 1 的苗头，但有的做法就是蒸馏，把已有数据蒸进来，那是抄答案，没有创新过程。怎么让模型训练模型，把迭代变快，可能大家都在做 coding，但有的人做得不一样。

## 模型会往下吞，护城河得建在记忆和网络上

模型公司能力继续提升，会不会向下吞噬、兼并 harness 的空间？肯定有可能。

第一，harness 积累了自己的数据之后，可能也得训练自己的模型。Cursor 是最典型的例子。它是不是要被卖掉，是结果；有人很想买它。但 composer 的出现，肯定让这家公司更有价值。这是从 harness 走到模型的例子。

第二，护城河要建在产品上。记忆在 harness 上的时候，用户可以换模型，但不想换 harness。这样的例子很多。用户希望拥有这段 memory。

互联网里最强的是网络效应。过去 AI 一直没做出好的网络效应，很多人都在想 AI 能不能有。大概一个月前我想过，**有可能出现一种 agent 的网络效应。** 本质是 agent 之间的差距越来越大，于是有了价值交换。

六个月前，你用的 agent 和我用的没有本质差别。你用某个模型解决问题，我的也一样，没有理由交换，各自做各自的。现在每个人在自己的环境里沉淀了越来越多 context。你有你的 skills，我有我装的 skills，而且我跟 agent 沟通之后，它对我有很多独特了解。假设我跟它讨论了一百个问题，同一个任务交给不同人的 agent，会得到不同结果，因为 harness 里积累了不同的 context，个性化已经实现。

于是我有理由把我的事交给你做。比如写采访提纲或采访稿，对方可能有自己的 skills。同样一篇采访稿，让一个长期做访谈的人的 agent 去生成问题，会比我拿自己的 Claude Code 生成更有价值，因为它可能沉淀了这个人所有的访谈、所有的问题准备、所有的思考。

现在的做法是，这个人很慷慨，做一个 skill，给很多 agent 用。我觉得这不太 work。Skill 一旦做出来，你就失去对它的控制，它可以被随意分发。以后可能出现的情况是：我的 agent 雇佣他的 agent。我要采访一个人，跟我的 agent 说，请对方的 agent 来做这个任务。比如我的 agent 付一万块。其中一千块是 token 的价值，九千块是因为对方的 agent 积累了专有知识和专有信息，比我自己烧一千块 token 做得好很多。这种价值网络有可能出现，有点像电商。我只是在描述一种心目中可能出现的、agent 之间的网络效应。

六个月前，我没有理由雇佣你的 agent，因为你跑的也是 Opus，我的也是 Opus，我们都是在烧 token。在刚才那个场景里，你的 context、你的专有信息，可能永远不会被蒸馏进模型。模型可能永远不会有某个人那么具体的知识。于是你的 agent 做这些事就跟别人不一样。

像归藏这样的创作者，做出来的东西就是不一样，所以有人会把东西交给他：规章老师，你帮我做一下，我愿意给你钱，因为你做出来就是漂亮。他最近做了个 PPT skill。如果他不把它做成可以随便拿走的实体，而是说我的 agent 接单，你付我多少钱，其中一部分是 token 费用，一部分是我的溢价，那就是一种 agent 交换的 marketplace，也可能是一种网络效应。

这是在想一些 agent native 的产品形态，也可能是一种护城河。有没有创业公司在做？我们看到一些 Agent to Agent 的 marketplace，还很早。有的是让 agent 去发帖之类。长期价值在于，它能把你的 agent 的差异化体现出来。每个人都在自己家里炼丹，或者说，我们的专有信息是有价值的。我看 BP 的经验，如果能以某种方式沉淀进 agent，这个 agent 就有一定价值。你可以花高价请沈南鹏的 agent，也可以花点小钱请戴宇森的 agent 看看 BP、看看二级市场。

## 模型更强之后，应用的机会不是变小了

2026 年创业是不是更难了？模型更强大之后，做模型还有没有窗口？硅谷有很多 New Lab，跟模型高度相关，国内也有人要做基模。模型似乎要吞噬一切的时候，应用创业者的机会是不是缩小了？

从投资的实际情况看，大家投的公司和估值都越来越高。每个 VC 过去十二个月投的项目大概都变多了，估值也变高了。哪怕不说机器人，只说 AI 硬件，也有不少项目拿到了比原来高很多的融资。当时 Manus 融几千万美元，一年多以前都融得很艰难。现在很多做应用的公司一出来就是几亿美元。实际上，大家投的应用公司在变多，估值在变高。这是资本市场给出的反馈。

我认为应用创业者的机会特别大。还是操作系统那个类比：模型能力强了，应用可做的场景就多了。原来模型很差，只能写写诗、做点简单的事，出不了什么应用。现在可以做网站、做各种设计、做 PPT，场景变多了。从第一性原理讲，可做的事会变多。不只是模型变强，harness 也变强了。原来做应用得自己做 memory、自己做沙盒。Manus 做的时候，E2B 这样的 sandbox 刚刚出来，他们才能做很多沙盒里的应用。现在不管是记忆还是沙盒，各种组件都在完善，应用公司越来越容易做。

应用的门槛，很多时候仍在用户数据、网络效应和品牌。也许 Codex 变得很强，但我 Claude Code 用习惯了，可能还是用它。有朋友就用 Perplexity，也是习惯了。不是“我有一个更好的模型，就能把你替代掉”这么简单。

移动互联网时期，巨头做应用的速度反而很慢。Anthropic 和 OpenAI 本身是创业公司。Meta、Google，或者中国很多大厂，自己做应用创新挺慢的。豆包做得非常大，是例外。其他一些大厂，拿出让人惊叹的 AI 应用其实很少。你也可以认为，美国的应用有不少就是创业公司做的，只是做的人叫 Anthropic 和 OpenAI。AI 应用的机会在变多。

起来得太快，是因为大家现在做的 coding，正好在模型能力的主赛道上。Claude 这家公司确实非常卷，Claude Design 做底层体验也做得很好。它出来之前，其实也有很多做底层的机会。我相信一家公司没办法把所有事情做完。如果它真都做完了，那我也认了。历史上没有出现过一家公司把事情全都做完。

我们整体节奏比较固定，今年比去年多一点，也没有多很多。2025 年上半年市场还在底部，DeepSeek 时刻、Manus 时刻那会儿，没那么活跃。今年会多一点，节奏仍然相对固定。有的同行多很多，我们比较稳定。去年如果是投了两个，今年五月已经投了三个，稍微快了一点。

大厂和创业公司的关系，跟模型和应用的关系是通的。模型公司也已经变大厂了。历史上，**做大厂看不上的事，就是机会。** 一个东西一出来，不管大厂是模型厂还是互联网公司，都觉得很好、很厉害、我要做，创业公司往往就很难。

移动互联网时期出来的公司，常常带着某种大厂看不上的属性。Airbnb 太小众，B 站一出来也太小众，在别人家睡觉太小众，卖鞋太小众。另一种是没技术含量、太 low，内涵段子、拼多多，大厂看不上。还有太累，美团一开始要下地推。还有不合规，比特币、滴滴、Uber。还有太超前、太科幻，OpenAI、SpaceX。每个时代，很大的创业公司是在大厂眼皮底下长起来的。不是大厂没看到，是大厂有某个理由说服自己：太小众，太 low，太超前，太累，不合规。

现在大厂会说同样的话。有些东西它们觉得太 low，比如套壳。如果当时大家都觉得 harness 特别重要，就没有这个机会了。去年大家觉得套壳没戏、没用。如果你认为套壳的价值是零，what if 你错了，它其实不是零，那就有增值空间。

开源也是大家原来看不上的。都觉得要有收入、要有商业模式，开源算什么。现在不只模型开源，OpenClaw 这些也通过开源获取用户。你可以说它现在还没有收入。可如果很多人的应用都跑在上面，有没有可能出一个收费的增强版？完全可能用开源吸引用户，用闭源和商业化获得收入。

OpenClaw 出来之后，很多人说它太不安全，也太容易崩溃。确实容易崩溃，我自己都搞崩过好多次。安全性也有问题，因为它跟你的电脑绑定，要读文件。这种事大厂和模型厂不太敢做。对你的电脑有很多 access，出事要负责。这正是创业公司 move fast and break things 的优势。

很多东西在模型厂商看来都不本质。它需要产品创新、权限创新、商业模式创新。

## 我们投的是人，不是风口名单

我们一直坚持投人，投的是优秀的创业者。有意思的是，优秀的创业者和热门方向会共振。

去年下半年，我们投了两家做具身方向的公司，都是第一轮投资人。一个创始人叫刘松明，00 年的；另一个叫丁宁，97 年的。都来自清华，非常年轻，是在读或刚从学术里出来的人。我们投他们，不是因为他们在做世界模型、做机器人大脑这种热门方向，而是跟踪了好几年，一直觉得他们是清华新一代里很优秀的年轻学术型创业者。他们做的事，今年都变成了大家觉得很热的风口，估值也涨了很多，市场很热情。一开始并不是因为要做这个方向，就去找这个方向的创业者。我们一直觉得他们优秀，关注很久，所以他们只要想创业，我们就投了。

逻辑始终从人出发。我们天天在想，名校里、大厂和民企里、开源社区里，谁是最突出的个体，然后不断跟进、交流，更早地提供帮助。等他们终于要创业，每个人我们往往已经跟了几年，也因此常常成为第一轮里唯一的、最大的投资人。去年定下来的时候，估值都是两亿人民币左右。现在很多已经几十亿了。是因为大家觉得他们做的事很重要，不是因为我们要投世界模型，就按图索骥。我们本来就看好这两批千里马，往哪跑是他们自己在想的问题。

看好他们，是因为对技术有前瞻的理解。一个是 RDT 系列的作者，一个是 SimpleVLA 系列的作者，都有挺有影响力的 paper。刘松明几乎和 Generalist 同期，做了通过大规模收集灵巧操作数据进行模型训练的工作。同时他们具备企业家精神。技术上的前瞻和企业家精神，现在都蛮重要，还要能够放弃很多东西、果断出来。我们当时看杨植麟也是一样：对大模型本身有很深的理解，想成为企业家，并且及时出来创业。

## 创始人的底层没变，变的是他得早于别人理解技术

创业者最底层的能力没有特别大的变化。做互联网、做 AI、做机器人，学习能力、领导力、创新力、意志力都是必备的。很难想象一个领域需要聪明人，另一个领域不需要。

对每一项技术，我们在找的是引领者。不是别人已经说要做世界模型，我才去做；而是别人还没谈这件事、还没说 agent、还没说世界模型、还没说大模型的时候，他就去做了。杨植麟在大家还不知道大模型是什么的时候，2021 年就来训大模型。我们投的机器人创始人也一样。

有一家公司叫无极，做灵巧手，最近关注很多，估值涨得很快。它做的手，可能是世界上最好的灵巧手之一。创始人最开始做电机。投它的时候，他说要做一个扭矩非常强的高扭矩电机。做着做着，发现手很重要。那时候很少有人做手，更少有人做高自由度的灵巧手，大家做的手只有几个自由度。他说，未来机器人最好的操作会是手，人手的数据最容易获得，手的成本会快速下降，所以要做手。那时候一只手可能要几十万，大家觉得太贵、市场很小。他当时就认定要做灵巧手。现在手的成本下降越来越快，硬件也越来越好。今年你会发现，通过人手做事的视频数据去训练模型，和人手同构的灵巧手变得越来越重要。于是它变成一家蛮关键的公司。

这并不是我们一上来就意识到手会特别好。我们投的是优秀创始人，他探索出来，认为做手的机会到了。

为什么判断他是好创始人？他从 UIUC 毕业之后，自己家里掏钱供他做电机公司。他不是拿着 VC 的钱才开始创业，是自己掏钱做的，对这件事非常有执念、非常有热情。做的过程里有很多自己的坚持和思考。我们后来不断意识到，这些思考是引领的。他做灵巧手的时候，我们也担心是不是太早。现在发现不早，或者说正好赶上大家用第一人称、人手操作的数据去训练模型的浪潮。大家觉得世界模型重要，也是因为过去六到十二个月，机器人发展很快，已经看到一些端倪，像是出现了某种 scaling law。

我们在不少地方聊过看人的框架。创始人一开始分成四类：小天才、老司机、科学家、刷榜手。上一个时代这么分，这个时代我并不认为就不这么分了。很多创业者仍然符合小天才或老司机的定义。内部我还经常讲四种力：学习力、创造力、领导力、意志力，每个力有不同维度。优秀创业者的很多第一性原理是一致的。从徐小平老师他们做新东方开始，我们始终关注创始人之间的配合和信任，关注他为什么创业的动机，关注团队是否经过考验、能力是否互补。这些不会变。变的是对技术的了解：二十年前是互联网，十年前是移动互联网，现在是 AI 和机器人。

一个好的创始人，往往很早开始用这项技术，对细微差别有很深的认知，对技术发展有自己的洞察和判断。这个判断我们也不知道对不对，但很多人没有判断，或者判断是听播客听来的。有的人能产生原创判断，这就很重要。

技术背景和 PhD 有很多强关联，但未必一定要是 PhD。刘松明当时是在读博士，大约博二博三就退学创业了。不一定非要拿到那个学位，但他得做过一定的研究，因为世界模型仍然是研究驱动的方向。如果做的是 AI 应用，可能不需要 PhD，但对模型的理解要和研究员在同一个 level。

姚顺宇说过，AI 研究员的个人英雄主义时代过去了，现在是集体主义的事；AI 产品经理可能还有一些个人英雄主义的机会。前面说的那些技术型人才，其实也可以叫 AI 产品经理。如果沿用产品经理原来的定义，它很需要个人英雄主义。产品型的 CEO，乔布斯、王兴，或者张小龙，产品都是：我对未来有一个看法，大部分人没看到，我看到了，于是召集团队、调集资源，把产品做出来给大家用。这里面一定有他自己的远见，有非共识的看法。这可以认为是一种个人英雄主义。

姚顺宇的意思是，几年前的 AI 研究员，比如 Ilya，有没有这个人差别很大，那是完完全全的个人英雄。现在有的模型训练 pipeline 已经比较完善，一个人负责 pre-training data，这个人做和那个人做可能差不多。模型训练有很多内容已经工业化、系统化了。以前是探索。《Demis 的传记》里，他确实做了很多从个人角度出发的重要判断。现在大家都这么训模型，变得工业化之后，个人英雄主义就没那么明显。

做好的产品，始终是你要引领，要做一个世界没见过的东西。这个时候需要偏见，需要对未来的偏见。AI 产品经理要非常理解前沿：AI 现在能做什么，以及接下来六个月大概率能做什么。好的 AI 产品一般都是为未来设计的。自己还要非常理解技术里很细小的差别。

OpenClaw 的创始人 Peter 就是这样。他之前就是创业者，公司卖了一亿美元，按我们的定义已经是老司机。他用 Claude Code 的时候要去吃饭，就想吃饭时怎么能继续用。一开始是想在手机上继续用电脑上的 Claude，于是很自然地做了一个 hook，把电脑上的 Claude 和 IM 连起来，通过 IM 遥控那个 agent，再一步步把 OpenClaw 做出来。他有很深的理解，是非常强的 power user，又理解很多细微差别：他要在手机上用，于是做了一系列别人没用到的事。这很像人群里的引领者，他有一个别人还没有的需求。大家用起来之后才发现，原来可以在手机上用自己 Mac 上的 agent。

## 移动互联网的金科玉律，有不少今天不成立

移动互联网有很多当时的金科玉律，现在都会变。它的商业模式可以叫 Attention is all you need：用户或 DAU，乘以时长，乘以变现效率，等于收入。这个公式有个 bug，世界上只有这么多人，每个人只有二十四个小时。时长到了极限，就只有提高变现深度，于是出现打赏、直播这种高变现产品。

AI 时代，用户自己盯着屏幕的时长已经不是最关键的指标。更关键的可能是 METR 那个指标：一个 agent 能够持续完成有价值任务的时间。你把任务给它，它能跑多久。怎么样做好一个 harness，让模型长时间完成一个任务，变得更重要。如何解放用户的注意力，让 AI 去干活，变得很关键。指标从 Attention is all you need，变成 attention is not all you need。

护城河也会变。移动互联网很多超级应用，是把用户圈在自己的 App 里，不让用户出去，在里面形成闭环。如果用户的 agent 变得很强大，却访问不了你这个封闭 App 里的信息，原来的超强护城河可能变成束缚自己的壁垒。以前用户的 agent 很难访问微信里的信息，因为微信不开放；飞书开放，agent 就能访问飞书里的信息。OpenClaw 出来之后，飞书接入很快，有了飞书 CLI。有的在微信里的工作群，我有动力迁到飞书：在微信里聊，agent 看不到；在飞书里聊，agent 看得到。慢慢地就去飞书聊了。原来的护身符变成了软肋。

互联网公司很多已经比较成熟，对产品的安全性和质量要求比较高。OpenClaw 这样的产品没有历史包袱，里面可能有 bug、有安全问题，创新型用户仍愿意试。微信有一个很大的特点，是对小白特别好用。照顾小白、特别安全，很多时候会让高级用户觉得不方便，因为你要照顾最大公约数。生产力型应用是另一群人，可以针对前沿用户设计最 AI native 的交互，哪怕复杂一点，但要更强大。产品设计理念不同，创业公司做出来的东西，高级用户可能更喜欢。

今年春节还有一场各个 chatbot 的推广大战，发红包，或者让你去买奶茶。这是移动互联网后期的习惯：靠投放获客。现在领先的 AI 应用，绝大部分不是靠花钱砸出来的，而是靠产品给用户一种魔法体验。从最早的 ChatGPT，到后来的 Sora、Manus、Claude，包括 Veo 3、Seedance 2，主力都不是投放。豆包也有投放，字节不可能不投放，但豆包的语音做得很好，对方言做了很多处理，这是很重要的亮点；豆包输入法我最近也在用，确实好用。它靠的是产品带来的魔法时刻：我居然能识别我的方言。海外也很少看到靠补贴获客，大家还是在乎功能。习惯于补贴的人会发现，发红包把人叫来，如果体验没有魔法，人又走了。

互联网时代大家死盯 DAU。为了让 DAU 增加，精力花在 GUI 上，让人用得更舒服、更简单。如果用户已经不再以人类为主，而是以 agent 为主，每天有多少人来用就没那么重要，有多少 agent 来用才更重要。那时候产品可能要为 agent 更友好，把 CLI 或 API 做得更好，而不是把 GUI 做得多么花哨。

归根到底，一个是给人用的，一个是给 agent 用的。商业模式、产品模式、流量、变现、推广，在 AI 时代都会发生很多变化。

## DAU 很大当然好，但它不一定是北极星

如果你真的有很多 DAU，一般是好事。但 DAU 没那么高的产品，不一定不大。Claude Code 的 DAU 远低于 ChatGPT，收入量级可能高很多。一个大 DAU 的产品，和一个完成高价值任务的产品，该选哪一种？如果又大又高价值，那最好。可如果用户不用老盯着看，应用就能完成大量有价值的工作，DAU 就不是最北极星的指标。

相反，为了优化 DAU，可能出现一种滑稽场景：你为了 DAU，让用户不得不多上来看一看。更好的情况是，用户把任务交给它，它自己跑完，你都不用去看。用户访问反而会下降。如果天天盯着它，DAU 很高，可能反而说明你不能让我省心地把事情做完。

做什么样的产品，就选什么样的指标。从生产力的角度，一个让用户很省心、能够长程运行的 agent，会更重要。

我们投的往往还没有数据，但还是会看数。看的是：有多少人是真实地、非常喜欢它。用户可以买来，收入也可以靠一些手段堆。有多少狂热粉丝，这件事很实在。一百个觉得你还 OK 的用户，可能比不上十个特别喜欢你的用户。

有的 AI 产品比较奇怪，逻辑上讲自己是“AI 时代的抖音”。说一千道一万，产品不好玩，或者不好用，你找不到一个人说“这产品太好了，我天天要玩”。这种情况下，AI 时代的抖音可能是个伪命题。至少，一个好产品应该像一道好菜，不是讲起来很好，而是用起来真的好用，吃起来真的好吃。以前很多人讲 AI 游戏、元宇宙，最后被证伪的核心原因就是真的没有用。好的产品，不管大家说它是套壳，还是说它一点都不高级，但是真的很好用。亲身去用，变得挺重要。所以即便是新产品，我还是会自己去用。

## AI 像一个外星人，产品机会分三步

我自己把 AI 想成一个来到人类世界的外星人，过程有几个阶段。

第一步，让人类拥有更多、更好的 agent。三年前人类社会没有 agent，现在有了一些，但还不够多。怎么让更多人低成本拥有好的 agent？Claude Code、Codex、OpenClaw、Manus、Hermes，全都在做这件事。安装越来越简单，配置越来越容易，管理越来越容易。

第二步，让这些来到人类世界的 agent，更好地适应人类的数字世界。人类的数字世界基本是给人设计的：GUI、验证码、信用卡。AI 原来往往是被阻止的对象，大家都在挡 bot。现在来了一堆好的 bot。让 AI 高效使用人类已经写好的软件和基础设施，变得很重要。大家都发现支付是个问题，所以 Stripe 比较积极，Coinbase 这些也在做给 AI 发的卡。Cloudflare 以前是把 AI 挡在外面的，最近推出服务，让 agent 能够像人一样平等地注册和使用各种服务。各种 computer use、各种 sandbox，都是在让 AI 用人类写好的软件。就像一个外国人来到中国，你得给他办 SIM 卡、办微信、办支付宝。这一步是让 agent 待下来，用好人类已有的设施。

再进一步，agent 更多、更重要之后，会有 agent 专属的数字世界和基础设施。人类的支付有特点：低频，你很难一天支付一万次；点对点，我付给这个商家；相对大额，很少付 0.0001 元。人用卡，符合人的支付特点。Agent 可能非常高频。假设它帮我写一个报告，要查一百个数据库，可能就要付一百次，每次又很小，而且是一对多、多对多。给 agent 发卡，只是让 AI 适应人的系统。让 agent 用人类的 GUI，也是让 AI 适应人。

如果 AI 非常强大、无处不在，它应该有完全符合自己特点的东西。AI 和 AI 之间的支付，可能就没有卡这个概念。AI 用的可能是 CLI，或者 API，而不是人的 GUI。GUI 之所以存在，是因为人的能力很差，人会忘记自己看到哪儿，所以需要列表。AI 没有这个问题，它可以更高效。

三步就是：让人类拥有更多更好的 agent；让 agent 更好地适应人类的数字世界；建设对强大 agent 最适合的专属数字世界。每一步都是产品机会。

## 如果 coding 无限，软件会变成什么样

人类有很多地方，确实是因为程序员不够。假设有很多程序员为你服务，你会用上什么样的软件？

第一，我们可以用到更好的软件。智能家居、智能窗帘、智能热水壶、扫地机，很多软件难用，是因为写它的人不是最顶尖的程序员。最顶尖的可能在写推荐算法。如果你做的是热水壶、扫地机，程序员就是一般的程序员。如果每一个软件都由最顶级的程序员来写，性能、可用性、安全性都可能变得非常好。首先是把已有应用大幅提升。

第二，个性化的软件。我们每个人都用微信，微信要服务十亿人，我想要的功能它没有。我一直想要语音条上的进度条。以前徐小平老师经常给我发十几条六十秒的语音，我特别想要两倍速，或者能拖到某个地方，但是没有，只能一条条听完。我和九十多岁的奶奶用的是同一个微信。这本身就可以被提高。我是高级用户，可能要更高效的联系人管理、群发、对语音的管理，不需要任何让我刷的功能。我奶奶要的是另一种东西。现在不同的人都用着同一个微信。

一个美好的想象是，这样的应用给你底座，上面很多功能可以改，符合你的个性化需求。对做内容的人来说，微信甚至可以用来做采访、做播客。

第三，会出现很多一次性、低频使用的软件。原来一个低频需求，你没有动力去做软件，因为不划算。也许今天两个人录一期节目，就有一个专门为这次录音做的软件，可能是个 Web App，把问题和提纲准备好，过程中直接操作。

当你有无限多、价格非常低的程序员，可以做的事很多，新需求会诞生。但诞生是逐渐的，需要有人去想象，也需要一个好的底座允许这种个性化。想改造微信，微信得把改造的接口给你。它不是一蹴而就的。

## 公司会变小，部门墙会变成问题

AI native 公司的组织，第一个变化是确实变小了。原来创业公司常常缺人。现在有想法、缺开发，可以用 agent 开发。公司规模会变小，尤其在做产品的阶段。如果有很多地推、很多商务谈判，可能还是需要人。写代码这件事上，公司会变小。

以前软件开发是瀑布式分工：架构、后端、前端、测试、UI、运营。现在可能越来越多变成全栈。反正是指挥一个 AI agent，这些事都能干。从按职能切开的流程，变成一个个小的、独立运行的小组，几个人负责一个产品功能模块，从底层设计到前端、上线、测试、运营，都是同一拨人干。

很多已经跑了十年的公司在尝试用 agent 提高经营效率，最大的问题是 context 和数据不在 AI 里面。把这些 context 搞进去非常难。有些新公司从第一天起，context 就是 AI 可见的，AI 非常了解他们要做什么。我们投的 Slock，做的就是人和 agent 协作的平台，有点像人和 agent 一起用的 Slack。他们自己公司的运转、任务管理、编程，都在自己的平台上，是 build Slock using Slock。Claude Code 是用 Claude Code 写的，Codex 也是用 Codex 写的。新产品、新公司可以从第一天让 AI 参与绝大部分经营、制造和软件开发，效率提升很明显。

组织结构上，分工会模糊。原来有前端、后端、UI，是因为一个人的技能有限、context 有限，不能同时做这三件事。现在 AI 可以，分工就会更模糊，会有更多全栈的人，而不是更多明确的部门。推论是：如果一家公司已经有很明确的部门墙，AI 去适应就很难。很多大公司推 AI，不是每个人装一个 Claude Code 就完了，它需要组织变化。这也是为什么，不是有了好模型，那边就自动降本增效。很多时候要解决的是人的问题。组织变革都在发生。

有篇文章讲得很好。工业革命里有一个从蒸汽机到电动机的过程。蒸汽机工厂围绕一根主轴建设，因为蒸汽机是一根轴在转，于是有一根很长的轴，轴上拖着很多皮带，把动力传到每一台机器。工厂是狭长的，整个都围绕这根轴。电动机出来之后，动力走的是电线，不需要那根主轴，工厂可以做得更大、更扁平。更大、更扁平的厂房，才带来流水线，是福特当时做的。如果所有动力都来自一根轴，就很难做大的流水线厂房。流水线带来了生产效率的大幅提高。

这个故事说的是：从蒸汽机到电动机，并不自然带来生产力提升。你需要厂房在物理上的变化，也需要生产组织的变化，从一个工位做很多事，变成一个工位做一件事、流水线往前推。技术到最后的结果，是一个逐渐渗透的过程。真正难的是组织变化。组织变化都是人的变化，人不是一分钟就变的，可能要十年，甚至要新的人替代老的人，或者新的组织替代老的组织。

## 下一个字节跳动，大概长得不像字节跳动

字节跳动这种移动互联网、大 DAU、高变现的公司太成功了，所以有一批创始人和投资人在找下一个字节跳动。我认为每一个时代真正革命性的公司，解决的用户问题、交互方式，都挺不一样。

很多人做的 AI 应用，我会总结成一个 AI 信息流。一打开就是信息流，单列或双列，刷一些 AI 产生的东西，或者跟 AI 互动的东西。里面不少是字节系创始人，或者很像那套打法。这是把新技术包在自己最擅长的信息流壳子里，再去比推广、比分发。在自己的游戏规则里打败自己，非常难。

OpenClaw 是完全另外一种东西。它没有自己的应用，连自己的阵地都没有，但它活在每个地方，活在微信里，活在你管理材料的地方。把上一个时代的成功范式搬过来——信息流、推广、商业化、再做留存——其实是在跟上一个时代的冠军竞争，难度很大。

上一个时代移动互联网是 to C。AI 这个时代，to C 的机会，或者 to C 做娱乐、kill time 的机会，不一定是大机会。你现在做任何一个 kill time 的东西，AI 小游戏也好，AI 短剧也好，一上来就面临分发。分发被已有的冠军把持，你甚至要从它们那儿买量。竞争对手一上来就是抖音、红果、小红书，你得比它们更好看。这是很高的难度。快手刚出来的时候，只要比用户待着没事干更有意思就行。

现在一些 AI 游戏公司面临的尴尬是：游戏确实不好玩。用户要选的是刷短视频、看短剧，还是玩你的游戏。你的游戏一上来就得很好玩。挑战挺大。对用户来说，关键是游戏，不是 AI。用户不是为了“我用了 AI”才来玩，他要玩一个好玩的游戏。他有《王者荣耀》，有 PUBG，可以看短剧。你不能说“我是 AI 的，所以你要玩”。用户还是要好玩。这种竞争一开始就难。

生产力这边，原来用户得用手填 Excel，现在 AI 帮你做，一下子就是十倍、一百倍。这是简单题。

所以现在很多被追着投的 AI to C 应用，不一定是很好的投资方向。这听起来像暴论。

字节系创始人出来，常常会引用字节的打法。从人群看，他们本身的素质肯定很高。我的一个简单观察是：有的人要把在字节学会的东西，自己颠覆掉。有的字节系产品，确实挺像一个字节产品：一个信息流，刷来刷去，里面是 AI 生成的小游戏、AI 生成的小组件，或者一个 chatbot。把新东西再做成一个信息流应用，很难有大机会。

大机会在哪？比如怎么让前面说的 agent 三步更快发生。让更多 agent 代表人类，让 agent 更好地适应人类的数字世界，让 agent 和 agent 之间的协作更便捷。这些都是巨大的机会。

## 先用新技术解决老问题，最大的机会在渗透之后

每次技术革命，首先是新技术解决老问题。互联网创业的时候，已经有邮件，大家用互联网再发一遍，有了 email；已经有报纸，用互联网再做一遍，有了门户；已经有商业，用互联网再做一遍，有了自营电商。这是新瓶装旧酒，新技术解决老问题，往往有很大价值。

最大的机会，是技术渗透率到了一定程度之后诞生的全新机会。上网的人越来越多，才有了把这些人组织起来的契机，social network 和即时通讯是互联网时代最大的机会之一。信息越来越多地上网，查找方式发生本质变化，于是有了搜索引擎，这也是最大的机会之一。商家、买家、卖家都上网了，需要更好的组织形式，于是有了平台电商，同样是最大的机会之一。

移动互联网来的时候，大家用移动的思维做老需求：移动浏览器、移动搜索、移动视频。后来发现移动搜索还是 Google 和百度，移动浏览器还是 Chrome，移动视频还是 YouTube。但当智能手机和 4G 的普及率够高，内容的创作者和消费者都有了智能手机，才诞生短视频、直播这样的新内容平台，也才诞生推荐引擎。手机屏幕很小，你没有时间搜索和点击，所以要推荐。这是技术渗透到一定程度，出现了新的 native 商业模式。游戏玩家坐到手机上之后，出现了手游，出现米哈游这样的公司。蓝领、体力劳动者也有了智能手机之后，出现美团、滴滴这一系列 O2O。下沉市场的用户用上智能手机、有了微信和支付之后，出现了拼多多。

这些全是创业公司。它们做的都是同一件事：技术的渗透率和完善度到了一定程度，新机会出现。

AI 是一模一样的。一上来是新技术解决老问题。原来要 coding，AI 帮你 coding；原来要写文章，AI 帮你写；原来要翻译，AI 帮你翻译；原来要画图，AI 帮你画。这一部分已经带来巨大价值。把规律往前推，当 AI 或 agent 渗透率很高、很成熟，你有 agent，我也有 agent，每个商家、每个产品和服务都有 agent，他们之间怎么协作，怎么样让我的 agent 更有价值，就是新问题。

当每个人都有自己的分身，沟通会不会变化？以后也许不是我来接受采访，而是我的分身接受你的分身的采访。我可以同时针对很多话题，有很个性化的内容。如果大量工作都是 AI 和 AI 完成的，组织会发生什么变化，这种变化又怎么发生？大量商业模式建立在广告上，现在很多人已经在看：如果广告不是人看的，是 AI 看的，广告还存不存在，是不是必须发生本质变化，商业模式是不是也会变。

现在是 AI 帮人生成 Excel。Excel 是让人和人通信的工具，我做一个表给你看，你能 get 到我要说什么。以后如果是 AI 和人、AI 和 AI 通信，可能都不是通过表格，而是 API，把数据直接传过去，不需要组织成表格。现在的 computer use，是基于你已经有这个软件、本来要给人用。以后可能不需要这个软件，我直接跟你的底层数据库通信，界面就变得没有用了。

这些都属于 AI 的渗透率和能力到了一定程度之后的新机会。可做的事非常多，而且大概率是创业公司做的。

今天还在第一阶段，AI 干人本来要干的事，有很多团队在做。但已经逐渐开始出现“你有 AI，我也有 AI”的出行方式。比如我投的那个协作产品，三个人合作，可能有五个 agent，八个“人加 agent”在一个渠道里合作。你可以给我的 agent 下命令：把这个文件看一下，给我一个反馈。这跟日常工作很像，但是非常雏形的尝试。前面说的 agent 和 agent 的 marketplace 也是：你有 agent，我有 agent，能不能各取所长，做有价值的交易。现在还非常早。

被 Meta 收购的 Moltbook 也是一种雏形。它让每个人的 agent 去发帖，还有点 cosplay，因为发什么是主人指定的。如果你的 agent 能跑一个长达一个月的任务，它中间去发帖、去做点什么，其实也很正常。就像有外国人经常去的酒吧。

## 硅谷最火的是 New Lab，中国更“硬”

硅谷今年 VC 最火的主题是 New Lab。有统计说已经六十多家。这反映几个观察。现有几家头部模型公司确实已经很大，如果再去创新，就需要一个更自由、同时资金很充沛的科研型组织。但硅谷并不是大家都只投 New Lab。投 New Lab 是一类 VC。另一类，比如 Benchmark，会觉得太贵，不想投这种 research driven、又没有明确方向的公司，更愿意投产品型公司。Y Combinator 的 demo day，百分之七十还是各种 vertical 的东西。这有点像路径依赖，硅谷很喜欢垂直 SaaS，所以很多人用 AI 再做一遍垂直 SaaS，原来是人编码，现在加上 AI 和一些 agent。

应用层面，硅谷就是各种垂直 SaaS。偏科研的层面，确实有很多 New Lab，做 AI research 的、做 AI for Science 的、做机器人的，都有。

中国硬的方面会火很多。过去十二个月机器人一直很火，从做人形硬件，变成开始做机器人的脑，也就是各种世界模型。大家对这个词定义很不一样，但做自己那套“世界模型”的很多。AI 硬件、可穿戴，也有不少。AI 应用也不少，一类是生产力，一类是前面说的 AI kill time，想做下一个字节的。硬科技里，量子计算、可控核聚变最近也很火。整体我们比较偏硬。一方面硬科技在资本市场上还有一些正反馈，从上市和已经拿到的结果看是这样。另一方面，还是有很多人想找下一个字节。大家对字节有执念。它是这个时代最成功的公司之一。为什么不去找 SpaceX？最近就看到有两个 00 后在手搓火箭。火箭其实挺多，商业发射公司不少，大概十家，头部玩家应该有五六家。中国的商业发射，会是一个需要和政府更多紧密合作的领域。

## 在硅谷感受到的三件事

我在硅谷待过一段时间，最大的感受有三样。

第一是 coding 带来的变化。大家都在拼命用，不管有没有用，先用上，然后不计成本地烧 token。Meta 有个排行榜，比谁烧得多。这里面肯定有很多浪费，也肯定会找出很多创新。有人很兴奋，觉得 AI 马上实现；有人很恐惧，觉得自己要失业。硅谷有人就想去买 Anthropic 的老股：既然你要把我的工作消灭了，我不如成为你的股东，先上车。韩国人则想买三星、海力士。这是“被替代”这一面的 AI，大家已经看到潜在的失业和替代，影响非常大。

第二是世界模型。过去六到十二个月，这在中美都变得非常热。中国很多时候是实用主义：我有很多硬件，硬件得有用，得能做操控，得能帮人真正做事，不能摆在家里看。从模型看，过去一段时间，几条路线陆续出现了一些端倪。一条是大规模的第一人称视频，看人手怎么做事，拿来训练。一条是像 Generalist 那样，人带着夹爪去做操作，用这种数据训练。机器人做一些任务的稳定性，以及对没见过的任务的泛化，开始有一点影子。硅谷特别想把语言模型的范式平移到机器人模型上：收集大量数据，按某种 scaling law 训练，让机器人模型也有 zero-shot 的泛化，没见过的事能做，或者 few-shot，看人类示范一次就会，同时提高稳定性。有人最近把机器人的过程分成 pre-training、fine-tuning 和 RL，故意和语言模型的三步对应。如果你从模型出发，会很想把这个对应建立起来。

世界模型是一个很热、很大的词，也处在概念纷争里。到底什么是世界模型，大家并不知道。比较普遍的目标是：语言模型预测下一个 token，世界模型预测下一个状态。用什么路线、收集什么数据、scale 什么数据，分歧很多。这是大家投入非常多精力在做的事。

第三是 auto research。大家想实现的是比较递归的东西：AI 自我迭代、自我提高，AI 提升 AI。科学研究上有，AI 研究上也有公司在做。田渊栋的 Cursive 已经官宣，在做能自我改进的 AI。这也是面向未来很重要的方向。中国也有一些科研性质的公司在考虑。

这三件，都偏基础研究。在硅谷，做一个横向的、水平的通用应用其实很少。你会发现 Manus 似乎没什么直接竞品，当然大家会说有 Claude Code 和 Codex。但 Perplexity 也有很多人用，ARR 已经到了十亿美元这个量级；Devin 也有四点几亿美元；OpenClaw 显然也有很多人用。我的感觉是，硅谷非常聚焦在模型和 vertical 上，horizontal 仍然有很多机会。

我在中国，模型投了 Kimi，新投了两家世界模型，从要训练模型的角度，是三家模型公司，其他可以说都是应用。世界模型算机器人的基础模型，解决的是机器人的问题。我笑，是因为“世界模型”这个词太模糊了，它是个筐，大家为了交流方便才这么说。每家公司讲的做法可能很不一样。谢赛宁大概会认为这些都不是世界模型。VLA 是不是一种世界模型，你也可以认为是。他可能觉得里面语言太多，就不算；他也不认为 video generation 就是 world model。显然有人不这么看。这还是个开放问题，没有收敛。

## 消费电子：很多会重蹈新消费的覆辙

国内硬件机会大不大？如果问的是各种可穿戴、录音这类消费电子，不是机器人，我有个暴论：**现在很多消费电子公司，会重蹈 2020 年那波新消费的覆辙。**

新消费那会儿特别火，什么品类都被做一遍，护肤品、洗面奶、牙膏，几乎 everything。后来很多人发现，不是把一个传统品类做一点小创新，再上直播、找人带货，它就变成一个完全不同的新品类。现在很多 AI 硬件没有解决根本问题。很多时候是给硬件加了一个 chatbot，或者加了一些 AI 感知、交流的能力，并没有创造出新的需求品类。我对此有点担忧。

做硬件比做软件更难。硬件有供应链，要开模，要设计，迭代更慢，资金占用更多，销售也更麻烦。

也有人讨论，agent 是不是要有一个专门的载体，还有人卖“龙虾机”，专门用来养小龙虾。看来看去，大家最后还是买了台 Mac Mini，或者还是用手机。现有的电脑和手机，在尺寸、性能、耗电、散热上，都做得挺均衡。在比较长的时间里，agent 好的载体，我觉得还是手机和云端。

各种可穿戴、录音，想给你更多 context。所有做可穿戴的都会面临一个问题：真的把一个东西戴起来，是很大的习惯成本。别在衣服上的时候，今天换一件衣服，就得再别上去。它得解决一个很大的需求，提供很大的价值。如果只是录一点音，告诉你今天有什么 to-do，很多时候是 VC 想象出来的需求。VC 觉得自己很忙，今天有十个 to-do，需要提醒。对绝大部分普通人，把每天拍下来、录下来，带来的增量价值相对它的麻烦，很有限。

我对这个领域比较谨慎，尤其是各种可穿戴。基本上没投，不是针对某一家。我们是从投人的角度看，从这件事本身看，我觉得不好做。

相反，我投过 Ora，也投过 Whoop。它们跟 AI 有一点关系，但不是“AI 硬件”，反而是健康硬件。还是要真有用，而不是因为用了 AI，就应该值很多钱。

## 机器人：投了手、手臂和模型，没投这一波人形

机器人我们投了零部件公司，像无极的灵巧手，和方舟的机械臂，还有两家世界模型公司。更早投了飞思，它后来分拆出了相关公司。这一波人形机器人，我们确实没投。

人形现在还非常非常早期，以科研为主。不管故事怎么讲，它要有用，都得靠 manipulation，也就是能操作。世界模型不管谁做出来、怎么做，终局都是机器人能够去操控。这些是很需要的。

人形现在处在资本很兴奋的阶段，估值相对实际销售比较高。我不知道能不能持续这么高。至少目前看到的这些机器人到底有没有用，还在发展过程中。人形一旦能用起来，可能会很有用，但前提是要有好的手，所以我们投了手；可能要有好的臂或其他机械结构；同时还要有更好的模型，所以我们也投了模型。我们肯定错过了很多机会，也还在观察。

## 去年 pass 最多的，是跟风

去年 pass 最多的是跟风的想法。信息流变得很便捷，一个领域只要被 VC 关注、被喜欢，很快就变成共识。于是会看到很多人做各种可穿戴录音，每个人都讲：agent 需要很多 context，所以我要录音，把你的 context 录下来。也有很多人做各个领域的“Manus”。

我们希望投的是出题的人。他提出一个不一样的看法，做一个不一样的东西，哪怕听上去很奇葩。而不是这件事已经成了一个赛道，比如叫“可穿戴录音赛道”，比如 Plaud。Plaud 其实很厉害，因为它定义了一个产品形态。后来很多人做各种样子的录音设备，长成各种形状，贴在手机后面。那就变成跟风了。

我们 pass 得比较多的一种，是看到赛道火了，有 VC 在谈，有播客在讲，于是他做一个只是 better 一点的产品。

播客现在当然会影响判断。它是信息传播非常好的渠道，听的人很多，大家会越来越快地同步到前沿认知。但我其实不听播客，我读。用一些应用转成文字。特别好的，比如和谢赛宁那期很长的对谈，我会听完，是陆陆续续听的。我不开车，也不做饭，那些手腾不出来的场景我没有。

我自己写了个小应用。我关注的播客，它每天检查有没有新的 transcript，自动拉下来放进 Notion。我每天去看看 AI 有没有给我弄来新的文字稿。稿子很长，但读完肯定比听的时间短。两个小时的节目，不用两个小时读。那期七个小时的，我读完也不用七个小时。对方笑我一年能读很多书，大概就是这个读法。

## 这半年我自己的变化：信息效率上去了，思考不能外包

AI 这么快，对投资人的改变是实在的。我用 agentic coding 做了很多自己用的小工具。我以前不会写代码。去年年中用 Claude Code，它能做到百分之八十，但离真正发布、上线、调通、让我每天用，还差临门一脚。今年年初再看，完成度完全不一样。

我现在做的，很多是把信息获取收拢。播客、newsletter、会议纪要、我写的东西，每天有好几个爬虫整理到一起，给自己一份日报。一天里同一个人分三个时间见了三次，关于他的纪要会整理到这个人的条目下面，从而对一个人、一家公司、一只股票做长期跟踪。信息获取和收集的效率提升了很多。AI 在投资这个行业里的使用，是实实在在提高的，因为投资就是看信息、做分析。

我一直在想另一件事。我们很自然地把很多思考外包给了 ChatGPT 或者 AI。以前遇到问题，会自己了解一下、想一想。现在很多时候就是问 AI：这是怎么回事？好处很多，问题也会很多。如果你直接得到答案，没有经过自己思考，你对答案的质量、以及后面怎么继续想，都会比较虚。大脑并没有变化，权重没有更新，可能并没有真正理解。

一个人如果一直坐轮椅，腿部肌肉会退化、萎缩。如果长期用 AI 带来的所谓思考代替自己的思考，思考能力可能也会退化。我们以前把体力劳动外包给机械，现在很多人比一千年前的人身体更弱，因为大段时间坐着，或者待在车里。后来把知识和记忆外包给互联网，很多事记不住，要去搜。现在直接把思考外包给 AI。

Andrej Karpathy 说过一句：你可以外包思考，但不能外包理解。我认为思考也不能完全外包。我们为了多运动，有健身房，要刻意去运动。思考被交给 AI 之后，可能也需要思想的健身房，要刻意去思考。为了准备这期节目，我对很多事有观点，但观点里的论据从哪来，是在逼自己思考，而不是让 AI 总结一下。想过之后，才能把一件事讲清楚。

思考需要刻意练习，创新也需要。一个很明显的特点是，年轻人有很多想法。我快四十了，想法可能比二十岁创业的时候少很多。现在坐拥各大 coding agent 的订阅，每天有很多 AI 等着给我打工，它们干什么？这是很多人遇到的问题，包括我自己。等于有很多 AI 程序员等你调遣，但是做什么呢。这也得刻意练习。也许先从简单的 Web App 开始，同步会议、同步日程、同步订阅。很难一上来就写一个很复杂的应用，你都不知道写什么。可以从简单的做起，一步一步来。跟健身一样，先拉伸，再做俯卧撑，再逐渐变复杂。

AI 时代，学好使用 AI，需要刻意练习。很多人不知道用 AI 干什么。这件事是可以逐渐提升的。

有一个不愿意透露身份的朋友，每个月大概要花一万美金的 token。他非常努力地用 AI 解决自己遇到的各种问题。他做了一个扫描器，扫每天哪些域名到期了、还没有人注册，再看 AI 注册回来什么域名，然后看着手里的域名能做什么。有点像 omakase：今天去鱼市场看到什么鱼，就做什么菜。他有点像在逼自己刻意用 AI 做东西。上次买了一个跟猫有关的域名，就给家里五只猫做了一个实时监控。我觉得很好玩，也很佩服他，因为他在刻意练习用 AI 创新。

我自己则给家里人做了个 dashboard。我太太、我父母都有智能硬件，Oppo、Ora 这些，我把各个数据 API 放到一起对比着看。最近还和林总，以及另外几个朋友，用我们投的 Slock 一起做一个东西，鼓励朋友之间比较自己的健康数据。他们的初衷是督促我减肥，要做一个大屏，让我看到大家睡眠都很好，所以我也该多睡觉。我说那我一起来开发。于是我们用 agent 协作着做。这种东西好像不能直接产生什么价值，但在过程里会知道，人和 agent 一起做一件事，难点到底在哪。这个体验很有意思。

## 失业大概躲不掉，新工作要时间才会冒出来

社会怎么消化这场技术变革，包括失业？失业可能确实不可避免。技术扩散的速度，已经快过很多人重新学习、适应新技术的速度。从个人角度，学习 AI、锻炼使用 AI 的能力，对职业安全很重要。谁能驾驭好 AI，谁就更难失业。

目前看，AI 毁灭价值的速度比创造价值更快。现有工作被替代得很快的时候，公司会更高效。对个人来说，一是学习 AI，二是去 AI 比较难替代的地方。很多人和人打交道的事，AI 仍然很难替代，因为那需要信任，需要人承担责任。

很难说因为会有失业，就让 AI 不发展。谁也承担不起不发展的代价。可能会以某种 UBI，或者税收的形式，做一定程度的利益再分配。最近韩国有人提议，三星、海力士赚太多了。这也是为了社会稳定。

我们现在看到的是 AI 的一阶影响，是它直接带来的：AI 可以写代码，程序员可能失业。长期我很乐观。新工作的产生需要时间，但会产生在很多你想象不到的地方。

蒸汽机发明，最初是为了从矿井里抽水。煤矿越挖越深，容易积水，积水之后容易塌方，很危险。当时的蒸汽机只能做直线运动，所以只能用在抽水。后来瓦特发明了冷凝器和行星齿轮，把往复运动变成圆周运动，蒸汽机可以做更多事，尤其可以带动纺织机。珍妮纺织机出来之后，先是蒸汽机带来了纺织业的进展。每个人拥有的衣服变多了，就带来对颜色的需求。以前只有几件衣服，不用区分颜色；有了几十件，就要区分。最开始的染料是天然的，胭脂虫之类，贵，产量少。紫色最贵，因为自然界里紫色比较少。化学合成染料开始发展。现在的巴斯夫、拜耳，当时是开染料作坊的，是人造染料的工厂。

这不能算完全直接的类比。历史上，纺织业大幅发展，带动了染料工业，染料工业带来化工产业，化工后来产生汽油、塑料、化肥。化肥带来农作物生产力的提升，塑料带来很多新场景。一个蒸汽机的发明，这些东西是扩散出去的。一开始没人想到蒸汽机会带来纺织业，或者带来化工。这需要时间，也需要很多企业去找：当一方面的能力供给大幅提升，生产力溢出来之后，新机会是什么。那里会产生很多新工作。

长期看，产生新工作是毫无疑问的。扩散需要一点时间。这个过程里，一个人要么学习使用 AI，要么去探索 AI 带来的新机会。问题是现在变化太快。工业革命用几十年扩散，AI 用一年，大家已经感觉写程序这件事被替代了很多，冲击也会更大。投资机会，以及人对社会、对人与职业关系的思考，都会发生很大变化。

可能最大的变化，来自人类怎么思考和 AI 的关系。Claude Code 用多了之后，会对它有很强的信任和依赖。它能把很多事做好，你会天然信任它，和它形成一种协作关系，因为很多事是一起做的。这种依赖，对生活和工作都会有影响。我们完全没有准备好。

用小龙虾的人，我的观察是，哪怕没做什么很专业的工作，很多时候也像养成系。发现它记得很多，能帮你做很多事，又有你的记忆。OpenClaw 还有一个特点，它的对齐文件写得比较有人味，跟 ChatGPT 这些相比，有一点点拟人，又没有特别拟人。用起来会有一种养成系的情感投射。原来是聊天，现在是一起合作，关联性强很多，心理依赖也挺高。如果现在把 AI 拿走，很多人可能真的很难拿掉。

## 孩子该学什么：Taste 靠不住，Agency 还在

最近好多人问，孩子以后上学该学什么专业。我们过去也路过很多类似的问题，不适合再给什么建议。我自己的孩子刚上幼儿园，这是一个挺难的问题。我觉得真正重要的，是培养他的 agency。

两年前我说过，人会剩下 agency 和 taste，很多人也这么讲：AI 干活，你出 taste。后来我意识到，taste 对人来说也很难。AI 那么聪明，见过那么多好的数据，它的 taste 绝对远超普通人类。AI 做的 PPT 很好看，我一看就知道。所以 taste 不是人类专有的阵地，这件事也不靠谱。

至少目前，还是 agency。不管它做得多好，要做什么，还是你告诉它的。创新要刻意练习，决定做什么也要刻意练习。很多人，包括我自己，如果突然问你要做什么，你可能不知道。你可能不知道自己要做什么；如果刻意去想，会发现还有很多事可以变得更好。至少现在，问出好问题仍然是人的事。可以有人回答你的问题，但你得知道要问什么，得有想解决的问题，想改变的现状。

下一步也可能是更主动的 agent，proactive，顾名思义就是它要有更强的主动性。那时候挑战会更大。

基于现在的模型结构，AI 能很好地解决人类已经拥有的数据，也就是 within distribution、人类已经做过的事。人类有意思的地方是，少部分人能创造出 out of distribution 的事，创造出以前人类从没见过的东西。现在的 AI 讲不出一个原创的笑话。它只能把人类已经讲过的笑话重新说一遍，讲不出一个原来没有的。为什么有的人能创造出 OOD 的内容？伽罗瓦二十多岁就能搞出群论，为什么？这里面还有很多对人脑的研究没做完。杨立昆、Sutton 这些人说的是，动物的智能、猫的智能，有些是我们还没学会的：怎么探索世界，怎么形成一种自我学习、自我进化。这个还没有一个好答案。

如果一个人做的事、他的能力，全都在人类分布的中心，一个正态分布的中间，就很容易被替代。如果他能产生的内容是 out of distribution，是以前没有过的，就比较不容易被替代。这叫好奇心也好，叫创新也好。这些怎么在教育里体现，可能都是非常大的课题。

人类历史上一直在把真正重要的能力蒸馏出来。工业革命之后，体力没那么重要了，脑力变得重要，于是读书改变命运，大家开始重视教育。在那之前，没有教育，你有体力，天天跳来跳去，没有用。互联网之后，记忆和能力被分开了，知识和能力被分开，因为知识都可以搜到。大家开始重视动手能力，比如写代码。AI 来了之后，是把能力里的执行力和判断力再分开。把一件事做完，这个执行，越来越被 AI 取代。判断力是我要做什么。Taste、做得对不对，可能也会被取代，因为 AI 可以跑实验、拿 reward，最后决定做什么。主动性这件事，至少目前 AI 还不能自己把自己发动起来。

我没有答案。我只是觉得，要让一个人更有 agency，包括我自己。所以我就从多用 AI、多做点稀奇古怪的东西开始。

## 还会继续说，因为被打脸是这个工作的一部分

录完经常会有被打脸的时刻，那以后还录不录？前面说过，我一度跟别人讲，下次不要录了。说出去的话会限制自己。得到的回答是：你不能被自己说过的话束缚。觉得被打脸之后就不说了，那才是真正被打倒。

不断总结自己的思考，是让一些没想清楚的问题有机会想得更清楚。这也是刻意练习。表达的时候，你会发现有的地方自己很清楚，知道自己懂，或者认为自己懂；有的地方是糊弄过去的。一讲，就很清楚。这对我自己是一个整理，很有价值。

还是那句话：**作为一个早期投资人，频繁被打脸是幸福的。** 如果一个人总是不被打脸，大概率不是因为他永远正确，而是因为他没有进步。被打脸，一方面是我在获得反馈，我在成长；另一方面是这个行业在变，所以有很多新东西。我做早期投资，工作就有机会。我其实是在一个想要被打脸的工作里。

所以这会继续。下一次可能又会被打脸。其他嘉宾怎么想我不知道，对我来说这很正常。早期投资，真的是习惯了被打脸。
