## 三年之后，最吃惊的不是技术，是没人觉得近

三年前聊过一次。若问这三年最大的变化、三年前的体感和现在差在哪里，底层技术——那条技术指数——大体就是当时预期的样子。这里加减一两年，那里再加减一两年，具体会先冲向代码这个方向，当时未必猜得准；可若只看指数本身，模型从「聪明的高中生」走到「聪明的大学生」，再走到开始做博士和专业工作，代码还要再往前探一截，前沿参差不齐，但大致就是预期中的行军。

真正吃惊的是另一件事：**公众几乎不承认我们离指数的尽头有多近。** 圈里圈外都有人还在翻那些嚼烂了的政治热点，仿佛周遭并不是一条指数正在收尾。这近得让人发懵。

三年前录那次的第一个问题是：缩放到底怎么回事？现在还想问同一个问题，只是它变复杂了。至少从外面看，三年前有众所周知的公开趋势：算力跨很多个数量级，损失怎么改善看得清清楚楚。现在有了强化学习的缩放，公开的缩放定律却没有，甚至「它到底在干什么」都说不清——是在教技能，还是在教元学习？此刻的缩放假说究竟是什么？

## 二零一七年那团「大计算」今天还没被打脸

这个假说其实从 2017 年就没换过。那年写过一份文档，叫「大计算团块假说」。上次提过。它当时并不是专讲语言模型怎么缩放的。写的时候 GPT-1 刚出来，也不过是许多路线里的一条：那时候还有机器人、把推理当成和语言模型分开的事来做、也有 AlphaGo 那种强化学习的缩放，OpenAI 做 Dota，DeepMind 做星际争霸、也就是 AlphaStar。文档写得更一般。过了几年，Rich Sutton 发表了「苦涩的教训」，内核其实一样。

它说的是：那些聪明巧思、那些技术、那些「我们得发明一种新方法才能做成某事」的念头，没那么要紧。真正要紧的只有几样，当时列了七条。

一是你有多少原始算力。二是数据有多少。三是数据的质量和分布，必须够宽、够广。四是你训练多久。五是目标函数得能「缩放到月球」——预训练的目标函数是这样一种；另一种是强化学习那种「你有一个目标，你出去把它达成」。这里面当然有数学和代码里那种客观奖励，也有人类反馈强化学习、以及它更高阶版本里那种更主观的奖励。六和七是归一化、条件化这一类：把数值稳定性搞好，让那一大团计算以层流的方式流过去，而不是半路撞上问题。

这个假说到现在还拿着。没看到多少真正对不上的东西。预训练的缩放定律只是其中一种表现，而且它还在继续给收益，对预训练的感觉也是好的，这点已经被广泛报道。变了的是：强化学习上也看到了同一件事。先是预训练阶段，再在上面加一个强化学习阶段。别的公司也在一些发布里写过：在数学竞赛上训练，AIME 或者别的类似比赛，模型表现和训练时长呈对数线性。这边看到的也一样，而且不只是数学竞赛，是一大类强化学习任务。强化学习上的缩放，和预训练上见过的是同一种。

## 「人类学习不该这么贵」——谜题是真的，但可能无关紧要

Sutton 本人其实相当不吃语言模型这一套。若把他的异议换一种不一定恭敬的说法，就是：真正抓住人类学习内核的东西，不该需要几十亿美元的数据和算力、外加专门搭出来的环境，才能学会用 Excel、做会计、用 PowerPoint、在浏览器里点来点去。我们得用这些强化学习环境把技能「砌」进去，恰恰说明缺了那个核心的人类学习算法，于是在缩放错误的东西。既然后面要的是能像人一样现学现会的东西，为什么还要做这么多强化学习缩放？

这里确实有一个真谜题，但它可能无关紧要。甚至多半无关紧要。

先把强化学习从这套说法里拿开。把强化学习说成和预训练有什么本质不同，是条红鲱鱼。看预训练：2017 年 Alec Radford 做 GPT-1 的时候很有意思。更早的模型练在分布很窄的文本上，标准的语言建模基准；GPT-1 自己练的是一大批同人小说一类的东西，文学文本，只占你能见到的文本的很小一块。那时候数据大概十亿词这个量级，又小又窄，看不见世界上大部分东西，泛化很差。在某种同人小说语料上变好，换到别的任务就不行。当时有一堆指标，衡量模型预测其他各类任务有多好，就是看不到泛化。

直到在所有任务上、在整个互联网上训练，做一次一般的网页抓取——Common Crawl 那种，或者抓 Reddit 上的链接，GPT-2 就是这么做的——泛化才开始出现。强化学习正在走同一条路：先从数学竞赛这种很简单的任务起步，再铺到代码，再铺到许许多多别的任务，泛化会越来越强。这样一来，强化学习和预训练的那一半对立就拆掉了。

谜题在另一边，而且预训练、强化学习都有：预训练用的是万亿级 token，人一辈子看不到万亿个词，样本效率确实不一样。模型从零开始，权重一开始就是随机的，得吃下多得多的训练。人脑不是白板，整本整本的书都在讲这件事；大脑带着脑区，接着各种输入和输出。语言模型白得多。所以预训练，以及强化学习，也许该被看成夹在人类进化和人当场学习之间的东西；上下文里的学习，则夹在人的长期学习和短期学习之间。

层次是这样的：进化，长期学习，短期学习，以及单纯的反应。大模型的各个阶段落在这根谱上，但不一定正好落在人的那些点上。有些人类学习的模式，模型并没有对应物，它落在点与点之间。

## 那为什么还要专门教它用 Slack？

若类比是进化，样本效率差就没关系；可若上下文学习很快就能给出那种超高样本效率、能现学现会的智能体，为什么还要有一堆公司专门教它调某个 API、用 Slack、用这个用那个？那种能当场学会的智能体，若正在出现、即将出现、或已经出现，这股劲头就让人糊涂。

别人把重心放在哪里，没法替他们说话，只能说我们自己怎么想。目标不是在强化学习里把每一种技能都教给模型，正如预训练也不是那样。预训练不会把词语的每一种拼法都摊给模型看。模型在大量东西上训练，然后跨过预训练达到泛化。从 GPT-1 到 GPT-2，这个转折是贴着看完的：会有那样的瞬间——你给模型一列数字，这是房价，这是面积，它把模式补完，做出线性回归。做得不算好，但它做了，而它从没见过这一模一样的东西。

搭这些强化学习环境，和五到十年前做预训练是一回事。要的是一整大批数据，不是为了覆盖某一份文档、某一种技能，而是为了泛化。

## 为什么是一年，不是十年

没有人再反对这个世纪里会有通用人工智能。分叉在于：一边说指数已经走到头；另一边看着同一条曲线说，2012 年就在进步，到 2035 年会有像人一样的通用人工智能。凭什么觉得是一年而不是十年？模型里明明已经能看见进化做过的事，也能看见人一辈子里的学习。

其实是两条主张，一条强，一条弱。先说弱的。

2019 年第一次看见缩放的时候，并没有把握。整件事大概是五五开。当时的主张是：这件事比任何人以为的都更可能发生。野到没有别人愿意认真考虑。也许有 50% 的机会，十年内走到那种被叫做「数据中心里的天才之国」的东西。现在对这件事的把握大概是 90%。很难再高过 90%，世界太不可预测。不可约的不确定性也许把上限放在 95%：你总能拼出一个 5% 的世界——好几家公司内部动荡、什么都没发生，然后台湾被入侵，晶圆厂被导弹炸毁——事情再被拖上十年。这是一个 5%。

另一个 5% 是：对能够被验证的任务非常有信心。写代码，除掉那种不可约的不确定性，一两年就会到；十年内还不能端到端地做代码，没有这种可能。哪怕在很长的时间尺度上，仅有的那一点根本不确定性，是无法验证的任务。规划一次火星任务，做一次像 CRISPR 那样的基础科学发现，写一部小说。这些很难验证。几乎可以肯定有一条可靠的路能走到，若还剩下一点点不确定，就在这里。

所以十年这个尺度上，大概 90%，已经是人能有的那种确定。说这件事到不了 2035 年，很荒唐；在一个神智正常的世界里，这种说法该被放在主流之外。

## 强调「可验证」，是不是就不信泛化？

把可验证强调成一条光谱、不同领域进度会分开，听起来不像人变强的方式。人既擅长能拿到可验证奖励的事，也擅长拿不到的事。若这些模型连泛化都不被真正相信，软件工程也许根本自动化不了——当软件工程师，有一部分就是写那种很长的备忘录，讲你对各种事情的大图景。

这里要分开说。从可验证的东西泛化到不可验证的东西，已经看得到相当多，所以才会「几乎肯定」。到不了的那种世界是：可验证的都做了，其中许多也泛化了，可那一边的格子没有被完全涂满。不是非黑即白。即便在泛化很弱、只在可验证领域里看得到泛化的世界里，能不能把软件工程自动化也不清楚，因为这行当本身就不只是可验证的输出。

写那种宏大愿景的长备忘录，更像是公司这份工作的一部分，不全是软件工程师这份工作的定义。但软件工程确实包括设计文档之类。顺便说，模型写注释已经相当不错。这里故意把主张说得比自己相信的更弱，好把两件事分开。

对软件工程师，已经几乎到了。用什么度量？有一种度量是多少行代码由 AI 来写。可若拿软件工程史上别的生产力改进来比，编译器把所有行都写了，行数和生产力提升的大小不是一回事。说「几乎到了」，指的是生产力提升有多大，不只是写了多少行。

这一点是同意的。关于代码和软件工程，做过一系列预测，反复被人听岔。把光谱摊开：大约八九个月前说过，AI 模型会在三到六个月内写出 90% 的代码行。至少在一些地方发生了，Anthropic 内部发生了，下游用这些模型的许多人也发生了。这其实是个很弱的标准。人们以为说的是：我们将不再需要 90% 的软件工程师。这两件事隔着几个世界。

光谱是这样的：模型写 90% 的代码；模型写 100% 的代码——生产力上这是很大一跳；90% 的端到端软件工程任务由模型完成，包括编译、把集群和环境搭起来、测功能、写备忘录；100% 的此类任务由模型完成；100% 今天意义上的软件工程任务由模型完成。即便走到那一步，软件工程师也不会失业，他们可以去做更高一层的事，去管理。再往下，对软件工程师的需求少 90%——这也会发生，但它是光谱上更远的一点。《技术的青春期》里用农业把这条光谱走过一遍。这些基准彼此差得很远，只是我们正以极快的速度逐个穿过。

从 90 到 100，一是会很快，二是会因此带来巨大的生产力改进。可即便在全新项目里，人们用 Claude Code 一类的东西起步，会开工很多项目，外面却还没看见一场软件的复兴，没看见否则就不会存在的那么多新功能。世界很复杂，工作很复杂。把闭环做死在一个自包含的系统里——哪怕只是写软件——由此能看见多大范围的增益，并不显然。也许因此就该把「天才之国」的估计往下泼一点冷水。

两头都成立：这些事不会瞬间发生，效应又会非常快。两极分别是：AI 不会有进展、很慢、在经济里扩散要永远；以及递归自我改进一来，你在曲线上画一条指数，递归之后多少纳秒我们就有戴森球包住太阳。后一极是漫画。从一开始看到的，至少在 Anthropic 内部，是一条怪异的、每年十倍的收入增长。2023 年从 0 到 1 亿；2024 年从 1 亿到 10 亿；2025 年从 10 亿到大约 90 亿或 100 亿。真该买下十亿美元自己的产品，好干干净净地凑满一百亿。今年第一个月，这条指数本该慢下来，却又加上了几十亿。曲线不可能永远这样，GDP 就那么大。今年也许会弯一弯，但即便规模铺到整个经济，它大概仍会相当快。

该想的是中间那种世界：极快，但不是瞬间。慢，是因为经济扩散，因为得把闭环合上，因为琐碎——变更管理、企业里改安全权限、有一段老软件会在编译发布前检查模型，得重写；模型能做，可你得告诉它去做，而它做完需要时间。到目前为止看到的一切，都和这个图景相容：一条快指数是模型能力，另一条快指数在它下游，是模型渗进经济。不是瞬间，也不是慢。比以往任何技术都快得多，但有限度。看 Anthropic 内部，看客户，采用很快，但不是无限快。

## 「扩散」是借口，还是真约束？

有一种犀利的说法：扩散是人们用的借口。模型做不到某事，就说是扩散问题。拿人来比的话，AI 天生的优势本该让新的 AI 上手比新人容易得多。AI 几分钟就能读完你的全部 Slack 和网盘；同一实例的其他副本可以共享全部知识；雇 AI 没有逆向选择，你雇的是已经审过的模型的拷贝。雇一个人麻烦得多，可人们还是一直在雇人，工资总量往上走到五十万亿美元这个量级，就因为人有用。原则上把 AI 整合进经济比雇人容易得多。所以扩散好像解释不了滞后。

扩散是真的，而且不必只归结为模型的局限。有人把「扩散」当口头禅，说这件事不大——说的不是那个。也不是说 AI 会按以往技术的速度扩散。它会快得多，但不是无限快。

Claude Code 就是例子。开发者要上手，极其容易，个人开发者可以直接用。大企业里的开发者没有理由不跟个人、跟初创公司里的开发者一样快地采用。能推的都在推，卖给大企业，大型金融公司、大型药企，全都在采用，而且比企业通常采纳新技术快得多。可任何一项功能、任何一款产品，Claude Code 也好，Co-work 也好，会先被整天泡在 Twitter 上的个人开发者、被 A 轮创业公司用上，比一家做食品销售的大型企业早上许多个月。

因素很多：过法务，给所有人开通，过安全和合规。离这场革命更远的公司领导是向前看的，可他们得说清楚：花五千万买这个 Claude Code 讲得通，它是什么，为什么帮我们，为什么让我们更有生产力。然后向下面两层解释。三千名开发者，怎么铺开。这种对话每天都在发生。能做的都在做，好让收入一年涨二三十倍而不是十倍。许多企业会说这太有生产力了，采购流程上抄近路。他们比当年只卖普通 API 时快得多——许多企业也在用 API，但 Claude Code 是更有说服力的产品。它不是无限有说服力的产品。即便是通用人工智能、强大的 AI、数据中心里的天才之国，也不会是无限有说服力的产品。它也许有说服力到：即便年收入已经在数千亿，还能一年涨三倍、五倍、十倍。这在历史上从没做到过，极难，但仍然不是无限快。

轻微放缓，这个可以接受。有时人们会说：能力已经在了，只是因为扩散，否则我们基本上已经是通用人工智能。不是。若真有数据中心里的天才之国，而你的公司不用它，这间屋子里的人都会知道，华盛顿的人都会知道。乡下也许不知道。我们会知道。现在没有。这一点非常清楚。

## 三年前那句预测对了，可白领工作并没有被拿走

具体预测很容易各说各话。三年前问过：从那时起再过三年该期待什么。答案是：和它聊上一个小时，会很难把它和一个受过良好普通教育的人分开。这句话是对的。精神上却不满足，因为当时内心期待的是：这样的系统就能把白领工作的大块自动化掉。与其在「像不像一个受过教育的人」上打转，不如谈你真正想要的终端能力，以及我们到底在哪。

拿一份比较懂的工作来问，不是因为它最重要，而是好核对。视频剪辑。这份工作有一部分是了解观众偏好、了解主持人和嘉宾的口味和取舍，好几个月把语境一点点攒起来。入职六个月时的手感和能力，模型能不能在岗位上、在飞行中捡起来？这样的系统什么时候该出现？

说的大概是：一场三个小时的访谈，之后有人进来剪。达里奥挠了挠头，这段可以剪掉；有一大段讨论对观众没那么有意思，另一段更有意思，于是做成这一刀。数据中心里的天才之国做得到。做法是：它能一般性地控制电脑屏幕，你把素材喂进去，它也能用屏幕上网，看你以前所有的访谈，看 Twitter 上人们对这些访谈的反应，跟你谈话、问你问题、跟你的团队谈，看你们历史上做过的剪辑，然后把这活干了。

挡住部署的，有一部分就是计算机使用还没到「真正精通电脑」的那一点。基准永远不完美，但 OSWorld 这类指标爬上来了：大约一年零一个季度前、计算机使用刚重新放出来的时候，大概是 15%，记不清精确数字，也可能更早只有 5% 上下；现在爬到了 65% 或 70%。也许还有更难的度量。计算机使用必须过一个可靠性的门槛。

还有一层，就算计算机使用解决了也还在。这些年一直想给自己搭各种内部的大模型工具。有些纯文本进、文本出的任务，本该死死落在这些模型的拿手范围里，却仍然雇人来做。比如：在这份文字稿里标出最好的片段。模型也许能做到十分之七，可没有一种持续的方式，能像带一个人类员工那样，跟它来回，让它把这活越做越好。缺的就是在岗学习。于是真正的一份工作还是交不出去。

有意思的是，到了编程智能体，人们不会说「在岗学习」是挡住它们端到端做完一切的原因。它们在持续变好。Anthropic 有工程师已经不写代码。以前这块 GPU kernel、这块芯片自己写，现在让 Claude 写。生产力是巨大的提升。看 Claude Code，对代码库熟不熟、模型是不是在公司干了一年，在抱怨清单上排不到前面。走的是另一条路。

会不会是因为代码有一种外在的记忆脚手架，就落在代码库里，而别的工作没有？编码之所以快，恰恰因为这份别的经济活动没有的独特优势。

可这么说的时候，隐含的是：把代码库读进上下文，人在岗位上需要学会的一切就都在了。不管它有没有被写下来、能不能拿到，你需要知道的一切都从上下文窗口里来了。我们以为的学习——「我刚入职，得花六个月搞懂代码库」——模型在上下文里就做完了。

该怎么想，并不清楚。确实有人在质感上报告这种体验。去年有一项 METR 的研究：有经验的开发者在自己熟悉的仓库里关 pull request。他们报告自己更有生产力了，自己感觉用了模型更强。可看真正合回去的产出，是 20% 的下降。用了这些模型，他们更没生产力。一边是人们的主观感觉，一边是宏观上软件的复兴在哪里，一边是独立评估里看不到你以为会有的生产力收益。这三块对不上。

在 Anthropic 内部，这件事毫不含糊。商业压力极大，还因为安全上做的事——自己觉得比别的公司做得更多——把日子弄得更难。要保住那条十倍收入曲线，还要守住价值观，压力不可思议。没有时间去「感觉自己很有生产力、其实没有」。这些工具让人有生产力得多。为什么担心竞争对手用这些工具？因为觉得自己领先，不想把这种东西交出去。若它暗中在降低生产力，不会费这个劲。终端生产力每隔几个月就在模型发布里看见。这件事骗不了自己。模型让你更有生产力。

那种「感觉更有生产力」确实会被上面那种研究在质感上预言到。可看终端产出，进步显然很快。递归自我改进的想法本该是：做出更好的 AI，AI 帮你做出下一个更好的 AI。看到的却是 Anthropic、OpenAI、DeepMind 每隔几个月在领奖台上换位置。就算你觉得这会停，因为你赢了或者怎样——若上一个编程模型真带来巨大的生产力增益，为什么最好的编程模型没有变成持久优势？

图景是：优势在逐渐变大。现在编程模型大概带来 15%，也许 20% 的总要素加速。六个月前也许是 5%。5% 登记不上。现在刚刚变成若干要紧因素之一，而且会继续加速。六个月前有好几家公司大体站在同一点，因为这还不是一个显著因素。有多家公司写出被用于写代码的模型，而阻止别人在内部使用我们的模型，我们也不是完美的。看到的一切，和这种滚雪球相容：10%，20%，25%，40%。往前走还有阿姆达尔定律，你得把所有挡住闭环的东西挪开。这是 Anthropic 最大的优先事项之一。整篇的主题都是软起飞：光滑的指数，虽然这些指数相当陡。

## 没有「在岗学习」，世界会不会其实变不了？

顺着栈往回看：在岗学习什么时候来？编程这个例子仿佛在说，我们其实不需要它。没有这种人类基本能力，也可以有极大的生产力提升，AI 公司甚至可能有数万亿收入。若这不是原意，该说清楚。可看大多数经济活动：雇了一个人，头几个月没什么用，然后慢慢攒起对语境的理解——这里说的「理解」其实很难定义——然后他们成了顶梁柱，对公司极有价值。若 AI 发展不出这种现学的能力，对「世界会有巨大变化」是有点怀疑的。

两件事要分开。

眼下的技术是两个阶段。预训练和强化学习：把一大堆数据和任务扔进模型，然后它们泛化。这像学习，但是从更多数据里学，不是在一个人、一个模型的一生里学。又一次，它坐在进化和人类学习之间。一旦这些技能学到了，它们就在。预训练模型知道的日本武士史比说话的人多，棒球比他多，电子学里的低通滤波器也比他多。它的知识比一个人宽得多。只靠这个，也许就能走到模型样样都更强的那一点。

现有框架再缩放，还有上下文学习。它有点像人的在岗学习，只是弱一些、短一些。你给模型一批例子，它真的会。上下文里发生真正的学习。一百万 token 很多，可以是人学习的好几天。模型重读一百万个词，人至少要几天或几周。

这两样，在现有范式里，也许就够走出数据中心里的天才之国。不敢打包票，但它们会给你其中很大一块。也许有缺口。就按现在这样，相信这已经够产生数万亿美元的收入。这是其一。

其二是持续学习，一个模型在岗位上学习。这件事也在做，别人想必也在做。未来一两年里有不小的机会把它解掉。没有它，已经能走完大部分路。数万亿的市场、也许全部的国家安全含义、以及《技术的青春期》里写的那些安全含义，都可以在没有它的情况下发生。同时也有不小的机会，一两年内走到那一步。想法有一堆，不全展开。其中一个就是把上下文加长。没有什么从原理上阻止更长的上下文工作。你得在更长的上下文上训练，然后在推理时把它们伺候好。两件都是工程问题，我们在做，假定别人也在做。

从 2020 到 2023，GPT-3 到 GPT-4 Turbo，上下文从大约 2000 涨到 128K。之后这两年好像还在同一个数量级附近。人们也报告，上下文再长很多，模型通盘考虑那段全文的能力会在质感上变差。内部到底看到了什么，才让人觉得一千万、一亿、甚至为了凑出像人那样六个月的学习而需要的十亿级上下文是走得通的？

这不是研究问题，是工程和推理问题。要提供长上下文，你得存下整个 KV cache，内存很难全放在 GPU 上，还得倒来倒去。细节到这一层，已经跟不上了——GPT-3 那个年代还知道哪些是权重、哪些激活要存。现在整个东西翻过来了，因为有了 MoE 之类。至于那种退化：有两个量，一个是你训练时的上下文长度，一个是你提供服务时的上下文长度。训练得很短、服务时拉得很长，也许就会退化。比没有好，你也许仍然提供它，但会退化。而在长上下文上训练，也许更难。

这里还有可以钻的兔子洞：若必须在更长的上下文上训练，同样的算力是不是就喂得进更少的样本？先不钻。更大的问题是：什么时候，一个跟了我六个月的人类剪辑，和一个跟了我六个月的 AI，我会不再偏好那个人类？

许多问题本质上都是：等我们有了数据中心里的天才之国，就能做。若一定要猜，一到两年，也许一到三年，很难说。有一个很强的判断，95% 到 99%：十年内这些都会发生。这是极稳的赌。另外有一个直觉，更接近五五开：会更像一到两、也许一到三年。天才之国，以及稍微不那么「经济价值显眼」的剪视频。

剪视频其实相当有经济价值。类似的用例很多。所以预测是一到三年之内。

## 诺奖级能力、负责任的算力，这两句话怎么放在一起

Anthropic 预言过：2026 年末到 2027 年初，会有这样的 AI 系统——能使用人类今天做数字工作所用的那些界面，智力匹配或超过诺贝尔奖得主，并且能与物理世界交互。两个月前在 DealBook 的访谈里，强调的又是公司相对竞争对手更负责任的算力缩放。这两幅图对不上。若真相信会有天才之国，你会想要尽可能大的数据中心，没有理由放慢。一个真能做诺奖得主能做的一切的东西，可寻址市场是数万亿。这种保守，在时间表比较温和时说得通；和公开说的进展速度，对不上。

其实是扣得上的。回到那句：快，但不是无限快。

按这个速率走。技术在这么快地进步。非常高的把握是几年内会到；直觉是一两年内会到。技术侧有一点不确定，但很有信心不会差得远。更不确定的是经济扩散。确实相信一两年内可以有模型达到天才之国，一百个数据中心里的天才之国。问题是：那之后还要多少年，万亿的收入才开始滚进来？

不保证是立刻。可能一年，可能两年，甚至可以把它拉到五年，尽管对五年存疑。于是有这样的不确定：即便技术像猜想的那样快，它拉动收入有多快，并不知道。我们知道它会来。可按购买数据中心的方式，差上两三年就可以是毁灭性的。

《Machines of Loving Grace》（《充满慈爱的机器》）里写过：这种强大 AI、这种数据中心里的天才之国，直觉是 2026，也许 2027。那是直觉。差一两年不会吃惊，但那是直觉。假设它发生了。那是发令枪。治好所有疾病要多久？这是驱动巨大经济价值的方式之一。你得做生物学发现，得把新药造出来，得走监管。新冠疫苗我们看到了：疫苗送到所有人，用了一年半。小儿麻痹症疫苗我们已经有了五十年，仍在非洲最偏远的角落试图根除它。盖茨基金会在尽全力，别人也在尽全力，仍然难。不指望大多数经济扩散都像这个这么难，这是最难的情形。可这里有真正的两难。落点是：它会比世界上见过的任何事情都快，可它仍有限度。

于是买数据中心的时候，看着的曲线是：每年十倍，已经走了每一年。今年年初看的是一百亿的年化收入跑率。得决定买多少算力。数据中心真正建起来、把容量订下来，要一到两年。等于在问：2027 年我能拿到多少算力？可以假设收入继续每年十倍，于是 2026 年底一千亿，2027 年底一万亿。那就可以去买一万亿——实际上更像五万亿的算力，因为是每年一万亿、买五年。若收入不是一万亿，哪怕是八千亿，地球上没有一种力量、没有任何对冲，能阻止破产。

脑子里有一块确实在想：它会不会继续十倍。可若只差一年，或者增长率是每年五倍而不是十倍，就不能在 2027 年买下每年一万亿的算力，否则就会破产。于是你落在这样一个世界：支撑的是数千亿，不是数万亿。你接受一种风险——需求大到你支撑不了那份收入；你也接受另一种风险——你错了，它仍然慢。

说「行为负责任」，指的其实不是绝对金额。花得比另外几家少一些，这点是真的，但说的不是那个。说的是别的：有没有想清楚，还是在 YOLO，这边丢一千亿、那边丢一千亿。印象是有的公司没把电子表格写下来，并不真懂自己在冒的风险，做事是因为听起来很酷。我们想过。我们是企业业务，因此更能靠收入，它不像消费业务那样易变。毛利更好，那是买太多和买太少之间的缓冲。买下的量能抓住相当强的上行世界，抓不住完整的每年十倍。要落到财务麻烦，事情得变得相当糟。想清楚了，做了这个平衡。所谓负责任，是这个意思。

## 真要是一屋子人类天才，五万亿为什么不买？

也许双方对「数据中心里的天才之国」定义就不一样。若想的是真正的人类天才、真正一整个国家的人类天才关在数据中心里，会很乐意买五万亿的算力去跑他们。就算摩根大通或 Moderna 不想用，手里还有一国的天才，他们会自己开公司。若卡在临床试验上——大多数临床试验失败是因为药没有效，不是别的——这点值得说清楚。

《充满慈爱的机器》里正好写了这一点：临床试验会比我们习惯的快得多，但不是瞬间，不是无限快。就算临床试验要一年才转化成收入、才能做更多药，你在 AI 实验室里还有一国的天才，你可以多用许多 AI 研究者。而且你还相信聪明人做 AI 技术会有自我强化的收益。数据中心可以拿去推进 AI 本身。每年一万亿的算力，相对于每年三千亿，增益是实质的，而且是大增益。

一万亿，有增益。可还有一种可能：他们在那之前就破产了。只差一年，你就把自己毁掉。这就是那个平衡。买得很多，买得不得了，买的量和这局里最大的玩家可比。可若问为什么没有签下从 2027 年中开始的十万亿算力：首先，生产不出来，世界上没有那么多。其次，若天才之国来的是 2028 年中而不是 2027 年中呢？你破产。

若预测是一到三年，看起来到 2029 年前后就该有十万亿量级的算力在爬坡。人类工资大约是每年五十万亿这个量级，你会想要那个十万亿。

不谈 Anthropic 的具体数字，谈整个行业。行业今年在建的算力，大概是很低的几十吉瓦，叫它 10 到 15 吉瓦。大约每年三倍。明年 30 或 40 吉瓦，2028 也许 100，2029 也许 300 吉瓦。每吉瓦一年大概一百亿、一百亿到一百五十亿这个量级。乘在一起，到 2028 或 2029，就是每年数万亿。你得到的正是你预言的那个数。这是行业的数。

若把 Anthropic 自己按每年三倍去乘，到 2027 或 2028 有 10 吉瓦，再乘一百亿，就是每年一千亿；而 2028、2029 的可寻址市场若是那个更大的数，这两笔对不上。具体数字不便给，但这个算法得出的数太小了。太小。

## 2028 年开始盈利，恰恰是你最该把钱砸回去的时候？

曾对投资者说过，计划从 2028 年开始盈利。而这一年，可能正好是天才之国出现的年份，进步、医学、健康、新技术都要被打开。这不正是你想把钱再投回业务、造更大的「国家」、让他们做出更多发现的时候吗？

盈利在这个领域是个古怪的东西。在这里，盈利并不是「花掉」和「投进业务」的度量。盈利发生在你低估了将要到来的需求；亏损发生在你高估了需求。因为数据中心是提前买的。

用一个玩具模型，数字是风格化的，不对应任何一家的真实账。假设一半算力用于训练，一半用于推理。推理的毛利高于 50%。稳态下，若你精确知道需求：一年为一算力付一千亿，其中五百亿支撑一千五百亿收入，另外五百亿用于训练，于是你盈利五百亿。这是行业一两年后向前看的经济学，不是今天的精确数，是风格化事实。唯一让它不成立的，是需求不到那五百亿，于是超过一半的数据中心用在研究上，你不盈利。你练出更强的模型，可你不盈利。若需求比你想的多，研究被挤压，可你能支撑更多推理，你更盈利。

想说的是：你先决定算力的量，然后你对推理和训练有一个目标愿望，可这个分割由需求决定，不由你决定。

听起来，预言盈利，是因为在系统性地少投算力。若你真的——

不是。是因为难预测。关于 2028、关于它何时发生，那是对投资者尽所能做的尝试。这些东西因为不确定的锥体而非常不确定。若收入涨得够快，2026 年就可以盈利。若下一年高估或低估，会甩得很厉害。脑子里那种模型是：业务一直投、一直投、上了规模，然后在某一个点变成盈利。不认为这个行业的经济学是那样工作的。

若理解对了：因为「本该有的算力」和「实际拿到的算力」之间有落差，我们某种程度上被迫盈利，可这不意味着会继续盈利。会把钱再投回去，因为 AI 进步这么大，想要更大的天才之国。于是收入高，亏损也高。

若每一年都精确预测需求，每一年都会盈利。大约一半算力花在研究上，毛利高于 50%，需求预测正确，就导向利润。这是那种盈利的商业模式，只是被「提前建设」和预测误差挡住了，看不清。

把 50% 当成给定常数，并不对。若 AI 进步很快，多缩放就能多进步，你就会花掉超过 50%，因而不把那部分做成利润。

你也许想把它缩放得更多。可记住缩放的对数线性回报。若把训练份额推到 70%，你得到的是一个只小了一点点的、1.4 倍那种量级的差异。多出来的那二百亿，因为对数线性，每一块钱对你的价值小得多。你也许会发现，把那二百亿投进推理服务、或者投进把事情做得更好的工程师，更值。50% 不是精确目标，它会随时间变。对数线性回报导致的是：你在业务上花的是一阶的那一块比例，不是 5%，也不是 95%，然后因为对数线性而收益递减。

在一个天才身上，收益递减也可以仍然很高。更一般地说，市场经济里的利润是什么？利润基本上是在说：市场上别的公司能用这笔钱做出我做不出的更多事情。

不便透露 Anthropic 的信息，所以继续用风格化数字，把行业的均衡推出来。为什么不是每家都把 100% 的算力花在训练上、一个客户都不服务？因为没有收入，就融不到钱，做不成算力交易，明年就买不下更多算力。为什么不是只服务当前的模型、再也不训练下一个？因为你会落后，然后没有需求。于是有一个均衡。它不会是 10%，也不会是 90%。当作风格化事实，就说 50%。这就是要说的。

而且会处在这样一个位置：你花在训练上的那个均衡比例，小于你在算力上能拿到的毛利。于是底层经济学是盈利的。问题是，买下一年算力的时候，有一个地狱般的需求预测问题。你可能猜低了，非常盈利，可没有算力做研究；你可能猜高了，不盈利，可你拥有世界上所有用来做研究的算力。

这只是这个行业的一个动态模型。

往后退一步：并不是说「天才之国两年内会来，所以你该买下这些算力」。你落到的结论很说得通，可那是因为天才之国看起来很难、路还长。想问的是：这套世界观，和一个说「离每年产生数万亿还有十年」的人，是相容的。

那不是这里的看法。很难看出 2030 年之前不会有数万亿的收入。可以构造一个说得通的世界：要三年。于是 2028 年我们得到真正的、数据中心里的天才之国；收入到 2028 年也许在很低的数千亿；然后天才之国把它加速到万亿。这基本上是扩散偏慢的那一端。再花两年走到万亿。那就是拖到 2030 的世界。即便把技术指数和扩散指数叠在一起，猜想也会在 2030 年之前到。

利润从哪来，也不是「世界归根结底算力受限、所以我们一直把算力做大」。把整个行业抽象成经济学教科书。少数几家厂商。每家可以把某个比例投进研发。服务有某个边际成本。那上面的毛利非常高，因为推理高效。有竞争，可模型也有差异。公司会竞争着把研发预算往上推，可因为玩家少——小数量厂商的均衡，记得是古诺均衡——它不会均衡到完美竞争、边际为零。若经济里有三家，各自理性行事，不会均衡到零。

眼下确实有三家领先的公司，而它们不在盈利。什么在变？

眼下毛利是非常正的。发生的是两件事叠在一起。一是我们仍处在算力的指数爬升期。风格化地说：去年练了一个模型，花费十亿。今年它产生四十亿收入，推理花费十亿。毛利 75%，这 25% 是那份「税」。这个模型整体赚二十亿。与此同时，因为指数爬升，我们花一百亿去练下一个模型。于是公司亏钱。每一个模型赚钱，公司亏钱。

说的那个均衡，是我们已经有了天才之国、数据中心里的天才之国，而模型训练的规模爬升更加走平了的均衡。也许仍在往上走，仍在预测需求，但它更平。

眼下这个世界里，若把每一个模型当成一家公司，它是盈利的。当然。可作为前沿实验室，生产函数的一大块就是训练下一个模型。若不做这件事，你可以在当前系统上盈利两个月，然后你不再有最好的模型，于是没有毛利。

那个到达它所能到达的最大规模的点，到来之后，均衡里仍有算法进步，可我们训练下一个模型所花的，和训练当前模型所花的大致相同。某一点上，经济里的钱会用完。这是「劳动总量固定」那种谬误。经济会增长。这也是贯穿全文的那个主题的又一个例子：有 AI，经济会比以往任何时候都快得多地增长，可现在算力一年涨三倍。不相信经济会一年增长 300%。《充满慈爱的机器》里说过：也许一年 10% 或 20%，但不会是 300%。到最后，若算力成了经济所生产的大部分，它会被这个盖住。

假设一个算力被盖住的模型。前沿实验室赚钱的世界，是它们继续做出很快进步的世界，因为你的毛利根本上受「替代方案有多好」限制。你赚钱，是因为你有前沿模型。没有前沿模型，你就不会赚钱。于是这个模型要求永远没有稳态。永远永远，你继续做出更多算法进步。

认为这是真的。这已经像一堂经济学课。我们永远停不下来谈经济学。

不认为这个领域会是垄断。律师们从不希望说出「垄断」这个词。不认为它会是垄断。可你确实会看到玩家数量很少的行业，不是一家，是很少几家。通常，垄断来自网络效应，Facebook，或者 Meta——总还是叫它 Facebook。玩家很少的行业，来自极高的进入成本。云就是这样。云里有三家，也许四家。AI 会一样，三家也许四家。原因是它太贵，需要那么多专门知识和那么多资本才能运转一家云公司。你得摆上全部这些资本，除此之外还得做成那些需要大量技巧的事。你走到一个人面前说，我要颠覆这个行业，这里是一千亿。对方说，好，我放下一千亿，同时还要赌你能做成这些人一直在做的所有其他事。而你进入的效果，是利润率下降。

经济里一直有这样的均衡：少数玩家，利润不是天文数字，毛利不是天文数字，但不是零。云上看到的就是这个。云非常同质。模型比云更有差异。人人都知道 Claude 是 Claude，Claude 擅长的和 GPT 擅长的不同，和 Gemini 擅长的也不同。不只是 Claude 擅长代码、GPT 擅长数学和推理。比这更细。模型擅长不同类型的代码。模型有不同的风格。这些东西彼此相当不同。于是会预期比云里看到的更多差异化。

有一个反论。若生产模型的全过程，AI 模型自己能做，那就会扩散到整个经济。可那不是「把 AI 模型商品化」的论据，那是「把整个经济一次商品化」的论据。任何人能做任何事，任何人能造任何东西，任何东西周围都没有护城河。不知道那个世界里会发生什么。也许我们想要那个世界。也许当 AI 模型什么都能做、安全和安保问题都解决了，这是经济把自己再次摊平的机制之一。可那是远在「数据中心里的天才之国」之后的事。

可以把这个潜在的点说得更细一点。一，AI 研究特别加载在原始智力上，而原始智力在通用人工智能的世界里会特别充裕。二，就看今天，很少有技术扩散得像 AI 的算法进步这么快。这暗示这个行业在结构上就是扩散性的。

代码走得很快，可 AI 研究是代码的超集，其中有些方面并不快。一旦我们有了代码、一旦 AI 模型走得很快，那会加快 AI 模型去做其他一切的能力。代码现在快，可一旦 AI 模型在建造下一代 AI 模型、也在建造其他一切，整个经济会开始按同一种步伐走。

地理上有一点担心。仅仅是离 AI 近、听说过 AI，可能成为一种分化因素。说 10% 或 20% 的增长率时，担心的是：硅谷、以及和社会上连着硅谷的那些地方，增长率可能是 50%，而别处比它现在的步伐快不了多少。那会是一个相当糟糕的世界。经常在想怎么避免这件事。

## 机器人会不会紧跟着被解决？

有一种普遍的怀疑，针对「极快的进步」。听起来持续学习总归会在几年内以某种方式被解决。可两三年前人们还不谈持续学习，然后我们意识到：这些模型明明过了图灵测试、在那么多领域是专家，为什么还没有它本可以有的用处？也许是这件事。然后我们解决这件事，又发现人类智能还能做另一件、而那是人类劳动的基础、这些模型做不到的事。为什么不认为后面还有更多这样的东西？为什么认为我们已经找到了人类智能的那些碎片？

先说清楚：持续学习可能根本不是障碍。也许只靠预训练的泛化和强化学习的泛化就走到了。也许根本没有这么一个东西。事实上，机器学习的历史上，人们提出来的障碍，后来溶解在那一大团计算里，这种事更强。人们谈过：模型怎么记住名词和动词；它们能懂句法，可不能懂语义；只是统计相关；你能懂一个词，可不能懂一段话；有推理，可你不能做推理——然后突然，代码和数学可以做得很好。有些是真的。对数据的需求是真的。持续学习也许是真的。可还是该把脚站在代码这样的东西上。也许一两年内，模型就能把软件工程端到端做完。那是一整项任务，是人类活动的一整块领域，而我们会说：模型现在能做了。

端到端，是不是包括设定技术方向、理解问题的语境，等等？是，那些都包括。

这听起来就是通用人工智能完成了。也许内部自洽，可它不像是在说 90% 的代码或 100% 的代码。

不是一下子跳到终点。那是一条很长的光谱。那些最终也会被做完。我们正在非常快地穿过这条光谱。

有点好笑的是，好几次播客里主持人会说：我们要追上那篇关于持续学习的文章了。每次都会让人忍不住笑。好像播客在写一篇论文。真相是，我们都在一起把这件事想清楚。有些东西能看见而别人看不见，如今这更多是因为能看见 Anthropic 内部的一大堆东西、还得做一大堆决定，而不是因为有什么了不起的、别人没有的研究洞见。在管一家 2500 人的公司。要产生具体的研究洞见，其实很难，比十年前难得多，比两三年前也难。

## 远程工人可以被整个换掉的时候，API 还怎么卖？

走向「一个能直接替换远程员工」的世界，按 API 计价还是不是最说得通的？若不是，给通用人工智能定价、提供通用人工智能，正确的方式是什么？

会有一大堆不同的商业模式，差不多同时被试验。API 这种模式比许多人以为的更耐久。若技术在指数式前进，意思就是：总有一块「过去三个月里才变得可能」的新用例表面积。你摆上去的任何一种产品表面，都始终有变得无关紧要的风险。任何一种产品，大概只在模型能力的某一段范围内说得通。聊天机器人已经撞上了限制：再变聪明，对普通消费者帮助不大。不认为这是 AI 模型的限制，也不认为这证明模型已经够好、它们变好对经济不重要。它只是对那一款特定产品不重要。

API 的价值在于：它始终提供一个非常贴近裸金属的机会，去建造在最新的东西之上。于是总有一条新的前沿：三个月前还不可能的创业公司和想法，因为模型在前进而变得可能。总会有一千个不同的人用不同方式试验模型，一百个变成创业公司，十个变成大的成功的创业公司，两三个真正成为那一代人使用模型的方式。基本上认为它会和其他模式并存，可 API 这种商业模式会一直在，因为永远需要让一千个人去试。

不是模型吐出的每一个 token 都值同样的钱。有人打电话说我的 Mac 不工作，模型说重启一下。有人没听过这句，可模型这句已经说过一千万次。那也许值一美元，或几美分。而若模型走到一家药企面前说：你们在做的这个分子，把那一端的芳香环挪到这一端，美妙的事情会发生。那些 token 可能值几千万。所以肯定会看到承认这一点的商业模式。某种程度上会看到按结果付费，也许会看到像劳动那样、按小时补偿的形式。这是一个新行业，很多东西会被试，不知道什么会变成对的那个。

人们得试，才能弄清使用这一团智能的最好方式。这一点可以接受。让人吃惊的是 Claude Code。创业史上，没有哪个单一应用像编程智能体这样被热火朝天地竞争过。Claude Code 是这个品类的领先者。这很让人意外。它看起来并不内在地必须由 Anthropic 来做。为什么必须是 Anthropic，或者 Anthropic 最后怎么除了模型还做出了一个应用？

其实发生得很简单。我们有自己的、擅长写代码的模型。2025 年初说过：时候到了，一家 AI 公司可以用这些模型，对自己的研究做出非平凡的加速。你需要一个界面，需要一套挽具去使用它们。于是鼓励内部的人去试验。没有说必须用哪一个。最初也许叫 Claude CLI，后来在内部改成了 Claude Code。它成了那种人人在用、内部采用很快的东西。看着它，就说：大概该对外发布。它在 Anthropic 内部采用这么快，而写代码是我们做的事情里的很大一块，我们有好几百人的受众，在某些方面至少能代表外部受众。看起来已经有了产品市场契合。那就发布。

我们自己在开发模型，我们自己知道最需要用模型做什么，这造成了一个反馈环。Anthropic 的一个开发者说，若它更擅长某件 X 就好了，然后你把这个烤进下一个模型。这是一种版本。还有普通的产品迭代：Anthropic 里有一大批写代码的人，他们每天用 Claude Code，于是反馈很快。这在早期更重要。现在当然有几百万人在用，外部反馈也很多。可能很快拿到内部反馈，就是好。这也是为什么发布的是一个编程模型，而没有去开一家药企。背景是生物学，可我们没有开一家药企所需要的那些资源。

你知道，有人还以为我们只是去喝杯咖啡、在街区走走。

## 让 AI 走好：进攻占优的世界里，制衡还管不管用？

谈让 AI 走好。无论我们对「走好」有什么想象，都得和两件事相容。一是建造和运行 AI 的能力正在极快地扩散。二是 AI 的种群、以及它们的智能，也会极快地增加。于是很多人将能造出巨大种群的不对齐 AI，或者那些只是想扩大自己地盘的、像公司一样的 AI，或者心理很怪的东西——像必应里的 Sydney，可现在它们是超人。在一个有许多不同的 AI、其中一些并不对齐、在外面跑的世界里，怎样的图景才是一个站得住的均衡？

在《技术的青春期》里，对「权力平衡」是怀疑的。特别怀疑的，或者说具体怀疑的，是：三四家公司都在造那些干巴巴的、仿佛从同一件事里衍生出来的模型，然后它们彼此制衡；甚至任意数量的它们会彼此制衡。我们也许生活在一个进攻占优的世界：一个人，或一个 AI 模型，聪明到足以做出伤害其他一切的事。

短期内，玩家数量有限。可以从有限的玩家开始：把防护做进去，确保每个人都做正确的对齐工作，确保每个人都有生物分类器。这些是眼下该做的事。同意这解决不了长期问题。尤其若 AI 模型制造其他 AI 模型的能力扩散开，整件事会变得更难解。

长期，需要某种治理的架构。它保住人的自由，同时又让我们能治理数量非常大的人类系统、AI 系统、混合的人机系统——那些混合的人类与 AI 的公司，或经济单元。得想：怎么保护世界免于生物恐怖主义？怎么保护世界免于镜像生命？也许需要某种 AI 监测系统，监测所有这些。可我们得用一种保住公民自由和宪法权利的方式把它建出来。

和其他任何事一样，这是一幅新的安全图景，一套新工具，一套新的脆弱点。若这件事花一百年、非常慢地发生，我们会习惯。我们已经习惯了炸药在社会里的存在，习惯了各种新武器，习惯了摄像头。一百年里我们会习惯，会发展出治理机制，会犯错。担心的只是这一切发生得太快。也许我们得更快地去想，这些治理机制怎么才能工作。

在一个进攻占优的世界里，下个世纪的进程被压进五到十年。可我们需要的机制还是那些。若制衡有效，它们在只有人类的时候也该有效；若无效，有了 AI 也不会有效。也许这和人类的制衡一样，从根上就注定。不过我们有 AI 可以请教。从根本上，这不像是一场完全不同的球局。

有某种办法让它发生。世界各国政府也许得一起把这件事做成。你也许得去和 AI 谈，谈怎样建造社会结构，好让这些防御成为可能。这远到——时间上不一定远，可技术能力上远到我们很难提前预料。不知道。不想把话说到那么远的前面。

## 田纳西州那条法案，和十年禁令

12 月 26 日，田纳西州议会提出一项法案，大意是：明知而训练人工智能去提供情感支持，包括与用户进行开放式对话，构成违法。Claude 试图做的事情之一，正是成为一个有思想的、有知识的朋友。一般而言，我们会面对各州法律拼成的拼布。普通人本来可以从 AI 得到的许多好处会被砍掉，尤其是《充满慈爱的机器》里谈的那些：生物学上的自由、心理健康的改善，等等。很容易想象这些被不同的法律打地鼠一样逐个打掉。而这类法案，看起来并没有对准真正担心的那些生存威胁。在这种背景下，为什么反对联邦对州 AI 法律的暂停令？

同时有很多不同的事在发生。那一条特定的法律是蠢的。立法者多半几乎不知道 AI 模型能做什么、不能做什么。他们觉得：AI 模型提供那种服务，听起来可怕，不想让它发生。我们不赞成那条法律。可被付诸表决的不是那个。被付诸表决的是：在没有任何看得出的联邦监管计划的情况下，禁止各州对 AI 做任何监管，为期十年。联邦监管得国会通过，门槛非常高。人们说他们有联邦政府的计划，可桌上没有实际的提案，没有实际的尝试。

鉴于《技术的青春期》里摆出的那些严肃危险——生物武器和生物恐怖主义、自主性风险——以及我们一直在谈的时间表，十年是永恒。这是一件疯狂的事。若这就是选择，若这就是逼我们选的东西，那我们就选择不要那条暂停令。这个立场的收益超过成本，可若这就是选择，它不是一个完美的立场。

该做的、会支持的，是联邦政府介入。不是对各州说「你们不能监管」，而是说「这是我们要做的，各州不能跟这不一样」。联邦说：这是我们的标准，适用于所有人，各州不能做不同的事。这种优先权，若是这样做的，会支持。可「各州什么都不能做，而我们也不做什么」，当时就觉得非常说不通，认为它不会经得起时间，而且随着你看到的那些反弹，已经开始经不起时间。

想要的，从透明标准开始。为了监测那些自主性风险和生物恐怖主义风险。随着风险变得更严重、我们有更多证据，就可以在一些有针对性的方面更激进，说：AI 生物恐怖主义真的是威胁，通过一条法律，迫使人们有分类器。甚至可以想象——取决于它最后有多严重，我们并不确定——我们得以一种智力上诚实的方式推进，事先说：风险还没有出现。可按事情前进的速度，完全可以想象这样一个世界：今年晚些时候我们说，AI 生物恐怖主义这件事真的严重，我们该做点什么。放进联邦标准。若联邦政府不行动，就放进州的标准。完全可以看见这个。

担心的是另一个世界。只考虑你预期的进步速度，和立法的生命周期。好处因为扩散的滞后而是慢的，慢到按当前轨迹，这床拼布似的州法会禁止掉很多东西。一个情感聊天机器人朋友就已经让人害怕了，再想象我们希望普通人真正体验到的那些好处：健康和健康寿命的改善、心理健康的改善。与此同时，危险看起来已经在地平线上。看不见多少东西能对得上。它伤害 AI 的好处，似乎远甚于对付 AI 的危险。成本收益在这里更说不通。

几件事。人们谈论有几千条这样的州法。首先，其中绝大多数通不过。其次，世界在理论上按一种方式运转，可一条法律通过了，不等于它真被执行。执行的人可能会说：天哪，这太蠢了，这意味着把田纳西州有史以来建造过的一切都关掉。于是法律常常被解释成不那么危险、不那么有害。当然，若你通过一条法律是为了阻止一件坏事，你也有同样的问题。

若能决定通过什么法律、事情怎么做——我们只是其中很小的一个输入——会把 AI 的健康收益周围的许多东西放松管制。会大大加快我们发现药物的速度。否则管道会堵住。管道没有准备好处理将要涌过它的一切。会把监管过程偏置到：我们有大量东西涌来，它们的安全性和有效性实际上会非常清楚、非常干净。美妙的东西。真的非常清楚，而且真的非常有效。于是也许不需要这一整套上层结构，那套东西是为一个「药物刚刚有效、还常常有严重副作用」的时代设计的。

与此同时，安全和安保方面的立法该相当显著地加上来。从透明开始，是试图不妨碍这个行业，试图找到平衡。有人批评那篇文章，说太慢了，若这么做，AI 的危险会来得太快。基本上认为：过去六个月，也许还有接下来几个月，是关于透明的；然后若这些风险出现、我们对它们更有把握——也许就在今年晚些时候——就得在我们真正看见风险的那些领域非常快地行动。做这件事的唯一方式是敏捷。立法过程通常不敏捷，可我们得向每一个相关的人强调这件事的紧迫。写《技术的青春期》，就是这个原因。希望政策制定者读，希望经济学家读，希望国家安全领域的人读，希望做决定的人读，这样他们才有希望比原本更快地行动。

有没有什么可以做、可以倡导的，让 AI 的好处更确定地落地？已经和立法机构一起做过：这里防止生物恐怖主义，这里增加透明，这里增加吹哨人保护。可默认情况下，我们在这里盼望的那些实际的东西，看起来非常容易，非常脆弱，容易被不同种类的道德恐慌或政治经济问题碰碎。

在发达世界，并不是那么同意。发达世界里市场运转得相当好。当一件事上有很多钱可赚、而且它显然是最好的可选项，监管体系其实很难挡住它。我们在 AI 本身上就看到了。一直在争取的，是对华芯片出口管制。这在美国的国家安全利益之内，几乎是国会两党每一个人的政策信念。反对它的论点，礼貌地说，可疑。可它还是没发生，我们把芯片卖了，因为那里有那么多钱。那么多钱压在上面。在那个情形里，这是一件坏事。可它在是一件好事的时候也同样适用。

若谈的是药物和技术的好处，并不那么担心这些好处在发达世界被妨碍。有一点担心它们走得太慢。该努力加快 FDA 的审批。该反对刚才说的那些聊天机器人法案。单独看，反对它们，认为它们蠢。可实际上认为更大的担心是发展中世界。那里没有运转良好的市场，我们已有的技术常常建不起来。更担心那些人被落下。即便疗法被开发出来，也许密西西比农村的某个人也得不到，那是发展中世界这份担忧的一个较小版本。

于是在做的是：和慈善家一起工作，和那些把药物和健康干预送到发展中世界的人一起工作，撒哈拉以南非洲、印度、拉丁美洲，以及其他发展中的地方。认为不会自己发生的，是这件事。

## 为什么中美不能各有一个天才之国？

为什么美国和中国不能各有一个数据中心里的天才之国？是不会发生，还是不该发生？为什么不该发生？

若这件事确实发生，我们可能面对几种情形。若是进攻占优，可能像核武器，只是更危险：任何一方都可以轻易摧毁一切。也可能是一个不稳定的世界。核均衡是稳定的，因为它是威慑。可假设不确定：若两个 AI 打起来，哪个会赢。这会制造不稳定。当双方对获胜概率的估计不同，冲突常常发生。若一方说有 90% 我会赢，另一方也说有 90% 我会赢，打架的可能就大得多。他们不可能都对，可他们可以都这么想。

这像是一个完全一般的、反对 AI 技术扩散的论据。而这可能正是这个世界的一个推论。最终会是。

另一个担心是：政府会用 AI 压迫自己的人民。一个国家已经在建造某种高科技威权国家。说清楚，这是关于政府的，不是关于人民的。我们得找到办法，让各地的人受益。担心的是世界被切成两块，其中一块以一种非常难以被挪开的方式成为威权或极权。政府最终会不会得到强大的 AI，并因而有威权主义的风险？会。政府最终会不会得到强大的 AI，并有一种坏的均衡的风险？会。两件都是。

可初始条件要紧。到某个点，我们得立下道路规则。不是说一个国家——美国，或者一个民主国家的联盟，后者会是更好的安排，只是需要比我们目前看起来愿意付出的更多国际合作——直接宣布：这就是道路规则。会有某种谈判。世界得面对这件事。希望的是：到那时，世界上的民主国家、那些政府更接近亲人类价值的国家，握着更强的牌，在道路规则被设定时有更多杠杆。非常关心那个初始条件。

三年前那次访谈，有一种方式让它显得过时：当时一直在问，好像两三年后会有某个关键的支点时刻。事实上，放到那么远，看起来就是进步继续、AI 更扩散、人们把它用在更多事情上。想象中的未来是各国坐到一起：这是道路规则，这是我们的杠杆，这是你们的杠杆。可按当前轨迹，每个人都会有更多 AI。其中一些会被威权国家使用，在威权国家内部，还有私人行动者和国家行动者之分。谁受益更多并不清楚。事先总是难测。互联网以一种超出预期的方式便宜了威权国家。也许 AI 会是反过来的。

精确地说：底层技术的指数会像以前一样继续。即便到了数据中心里的天才之国，模型仍可以继续变聪明。有一个问题是：它们在世界上的价值，收益会递减。在你已经解决了人类生物学之后，你能做更难的数学、更晦涩的数学题，可那之后没有什么再要紧。把这个放在一边，指数会继续。可指数上会有某些可区分的点，公司、个人、国家到达这些点的时间不同。

《技术的青春期》里谈过：核威慑在 AI 的世界里还稳不稳。不知道。可那是一个例子：有一件我们视为当然的事，技术可能到达一个水平，至少我们不再能对它有把握。再想别的。也许有这样的点：你到达某一点，就有了进攻性的网络主导，此后每一台计算机系统对你都是透明的，除非对方有对等的防御。不知道关键时刻是哪一个，或者是不是只有一个。可认为要么有一个关键时刻，要么有少数几个，要么有一扇关键的窗户：AI 从国家安全的视角赋予某种巨大优势，而一个国家或一个联盟比别人先到达。

不是在主张他们于是说：好，现在我们说了算。不是这么想的。对方总在追上来。有些极端行动你不愿意采取，也不该采取。无论如何不该去取得完全的控制。可当那一点发生，人们会明白世界变了，会有某种谈判，暗的或明的，关于 AI 之后的世界秩序长什么样。兴趣在于：让这场谈判成为古典自由民主握有一手强牌的谈判。

文章里有一句：专制简直不是人们在强大 AI 之后的时代所能接受的政府形式。这听起来像是在说，作为一个制度，中国共产党在我们得到通用人工智能之后不能存在。这像是一个非常强的要求，似乎隐含着：领先的实验室，或领先的国家，将能够、并且按这种措辞应当能够决定世界如何被治理、什么样的政府被允许、什么样的不被允许。

那一段是「你甚至可以再走远一点，说 X」。并不必然赞同那个说法。相信的是更弱的一件：我们得非常担心威权主义者，该试图制衡他们、限制他们的权力。你可以把它带向一种干预主义得多的看法：带着 AI 的威权国家是那种自我实现的循环，非常难被挪开，于是你得从一开始就把它们除掉。这正好有你说的全部问题。若你承诺推翻每一个威权国家，他们现在就会采取一大堆行动，而这可能导致不稳定。那也许做不到。它可能成为正确的看法，也可能太极端，成不了正确的看法。

真正赞同的那一点是：今天，至少在多数西方世界的看法里，民主是比威权更好的政府形式。可若一个国家是威权的，我们的反应并不像他们犯下种族灭绝时那样。担心的是，在通用人工智能的时代，威权会有不同的含义。它会是一件更重的事。我们得用某种方式决定怎么对付它。

干预主义的看法是一种可能的看法，当时在探索这类看法。它可能最后是对的。它也可能太极端，成不了对的。可确实有希望。一份希望是：我们已经看见，随着新技术被发明，政府形式会过时。《技术的青春期》里提过：封建主义基本上是一种政府形式。然后我们发明了工业化，封建主义不再可持续，不再说得通。

为什么这是希望？这难道不能意味着民主不再是有竞争力的体系？

可以。它可以走任一方向。威权的这些问题会变得更深。好奇的是，这是不是威权还会有的其他问题的一个指标。换句话说，因为威权变得更糟，人们更怕威权，于是更努力地阻止它。你得用总均衡来想。它会不会促发出新的思考方式，用新技术保存和保护自由？更乐观地，它会不会带来一种集体的清算，一种更 emphatic 的认识：我们视为当然的某些个人权利有多重要？一种更 emphatic 的认识：这些东西我们真的不能交出去。我们已经看见，没有别的真正行得通的活法。

有一种说法听起来太理想主义，可确实相信它可能成立：独裁在道德上过时。它们变成道德上无法运作的政府形式。而由此产生的危机，足以迫使我们找到另一种方式。

这里有一个真正难的问题，历史上我们不得不以某种方式走出来。1970、1980 年代的中国，我们决定：即便它是威权体系，我们也与它交往。事后看，这是对的，因为那是一个威权国家，可十亿以上的人比否则会有的状况富裕得多、好得多。并不清楚若不这么做，它就会不再是威权国家。你可以看朝鲜。保持一个继续凝聚自身权力的威权国家，并不需要那么多智能。可以想象一个朝鲜，它的 AI 比别人的差得多，可仍够用来保住权力。

一般而言，我们是不是就该持这种态度：AI 的好处，以它对人类的种种赋能、健康等等的形式，会很大；而历史上我们认定，把技术的好处广泛传播是好的，即便传到那些政府是威权的人民那里。这是一个正和的世界，技术仍然值得扩散。对 AI，该怎么想是个难问题。

有许多选择。把它框成政府对政府、国家安全用语里的决定，是一个镜头，可还有许多别的镜头。可以想象一个世界：我们生产出这些治病的疗法，把疗法卖给威权国家是可以的，数据中心不行，数据中心里的芯片不行。AI 产业本身不行。另一种可能是——人们该想想——能不能有一些发展，要么作为 AI 的自然结果发生，要么我们通过在 AI 之上建造技术让它发生：一种均衡，威权国家若要否认人民对技术好处的私人使用，会变得不可行。能不能给威权国家里的每一个人他们自己的 AI 模型，这种模型保护他们免于监视，而威权国家没有办法在保住权力的同时镇压这件事。不知道。若走得够远，这听起来会成为威权国家从内部解体的理由。也许有一个中间世界：若威权者想保住权力，他们就不能否认对技术的个人化访问。

对更激进的那个版本确实有希望。技术会不会内在地具有某些性质，或者我们以某些方式在它之上建造，就能造出对威权结构有溶解作用的性质。最初我们希望过。若想到奥巴马政府初期，我们最初以为社交媒体和互联网会有那种性质，结果没有。可若我们带着「多少事情可能出错」的知识，用一种不同的技术再试一次呢？不知道行不行，可值得一试。

这非常难预测。有第一性原理的理由说明威权者可能会发展 AI。我们得承认这个问题，然后想出十件可以试的事，试那些，再评估它们有没有用、哪一件有用，若旧的不行，再试新的。

今天的说法是：不卖数据中心——对不起，不卖芯片，于是也不卖在中国制造芯片的能力。某种意义上，你在否认那会给中国经济、中国人民带来一些好处。那也会给美国经济带来好处，因为这是一个正和世界，我们可以贸易。他们的国家用数据中心做一件事，我们的做另一件。可你已经在说，为了赋能这个国家，那份正和的津贴不值得。

要说的是：我们即将进入一个世界，增长和经济价值会来得非常容易。若我们能建造这些强大的 AI 模型，增长和经济价值会来得非常容易。不会来得容易的是好处的分配、财富的分配、政治自由。这些才是难实现的。想到政策时，认为技术和市场会把根本的好处送上门，几乎快过我们消受的速度。而关于分配、政治自由和权利的这些问题，才是真正要紧的，政策该聚焦在这里。

## 劳动力不再稀缺之后，发展中国家靠什么追？

分配这件事，还有发展中国家。许多时候，追赶式增长比我们希望的弱。可当追赶式增长确实发生，根本上是因为他们有未充分利用的劳动力。我们可以把资本和诀窍从发达国家带过去，然后他们可以增长得相当快。在劳动力不再是约束因素的世界里，这个机制不再工作。希望是不是基本上靠那些立刻从 AI 致富的人、或那些因创造出 AI 而致富的国家来做慈善？

慈善显然该起一些作用，像它过去起过的那样。可增长若能变成内生的，总是更好、更强。在一个由 AI 驱动的世界里，相关的产业是什么？看，有很多东西。不该在中国建数据中心，可没有理由不在非洲建。事实上，在非洲建数据中心会很好。只要它们不属于中国，我们就该建。认为这是一件很好的事。

也该建造——没有理由不能建造——一个由 AI 驱动的制药产业。若 AI 在加速药物发现，就会有一大批生物技术创业公司。让我们确保其中一些发生在发展中世界。当然是在过渡期间。我们可以再谈人类完全没有角色的那个点，可人类在创办这些公司、监督这些 AI 模型上仍会有一些角色。让我们确保其中一些人类是发展中世界的人，这样快的增长也可以在那里发生。

## 宪法该对齐谁：用户，还是一套价值？

最近宣布 Claude 会有一部宪法，对齐到一套价值，而不必然只对齐终端用户。可以想象一个世界：若它对齐终端用户，就保住了我们今天世界上的权力平衡，因为每个人都有自己的 AI 在为他们主张，坏行动者和好行动者的比例保持不变，而我们今天的世界看起来工作得还行。为什么更好的做法不是这个，而是让 AI 携带一套特定的、要往前带的价值？

也许不该完全按这个方式画这条分界。这里可能有两个相关的区分，而问题里混在了一起。

一个是：我们该给模型一套「做这个、做那个」对「不要做这个」的指令，还是给它一套关于如何行动的原则。这纯粹是一件实践的、经验的事。观察到：教模型原则、让它从原则学习，行为更一致，更容易覆盖边缘情形，模型更可能做人们要它做的事。换句话说，若你说不要告诉别人怎么短接一辆车的点火线、不要说韩语、不要这样不要那样，给它一张规则清单，它并不真懂这些规则，也很难从中泛化。那只是一张该做和不该做的单子。而若给它原则，然后它有一些硬的护栏，比如不要制造生物武器，总体上你在试图让它理解它该瞄准做什么、该如何运作。只从实践看，这就是训练模型更有效的方式。这是一块。规则对原则的取舍。

另一件是可纠正性，对上内在动机。模型该在多大程度上像一套皮肤、你给什么指令它就直接照做；又该在多大程度上有一套内在价值，然后自己出去做事。在这里，关于模型的一切，实际上更靠近「它大体上该做人们要的事，大体上该跟随」。我们不是在试图建造一个自己跑去统治世界的东西。我们其实相当远地站在可纠正的这一侧。

我们确实说：有某些事模型不会做。宪法里以各种方式说过：正常情况下，若有人要模型做一项任务，它该做那项任务。这该是默认。可若你要它做危险的事，或者要它伤害别人，模型不愿意做。于是实际上把它想成一个大体可纠正的模型，带有一些限制，而这些限制基于原则。

根本的问题就成了：这些原则如何被决定？这不是 Anthropic 独有的问题，任何一家 AI 公司都有。可既然是把原则写下来的那一方，这个问题就问到这里。通常一部宪法是写下来、刻在石头上，并有一套更新和修改的程序。这里它看起来像一份 Anthropic 里的人写的、随时能改的文件，而它引导的系统会成为大量经济活动的基础。这些原则该怎么设定？

也许有三种大小的环，三种迭代的方式。

一是在 Anthropic 内部迭代。我们训练模型，不满意，就改宪法。把更新公开，过一阵子放出一部新宪法，说这是新的。这是好的，因为人们可以评论。

二是不同的公司会有不同的宪法。Anthropic 放出一部，Gemini 的模型放出一部，别的公司也放出。然后它们可以彼此看，外部观察者可以批评，说我喜欢这部宪法里的这个、那部里的那个。这制造某种软的激励和反馈，让所有公司取每一种里最好的元素，再改进。

三是 AI 公司之外、甚至不只是那些对宪法作评论却没有硬权力的人之外的社会。做过一些实验。几年前和好像叫集体智能项目的组织做过一次：去问人们，我们的 AI 宪法里该有什么，当时纳入了其中一些改变。用我们现在对宪法的新做法，可以想象再做类似的事。会难一点，因为那次其实更容易——宪法当时像一张该做和不该做的单子。到了原则这一层，它得有一定的融贯。可你仍可以想象从非常多样的人那里取得看法。

也可以想象——这像一个疯狂的想法，可整场谈话都是关于疯狂的想法——代议政府有输入。今天不会这么做，因为立法过程太慢。这正是认为该对 AI 监管里的立法过程小心的原因。可原则上没有理由不能说：所有 AI 模型必须有一部以这些东西开头的宪法，然后你可以在后面附加别的东西，可必须有这一段特殊的、优先的部分。不会这么做。那太僵。那听起来过于规定性，像过于激进的立法。可有没有一种重手轻得多的版本？也许有。

第二种环很让人喜欢。这显然不是真实政府的宪法运作的方式，也不该是：最高法院不会去感觉人们的情绪和氛围、然后据此更新宪法。真实政府有一套更程序化的过程。可你实际上有一个愿景：宪法之间竞争。这非常像一些自由至上主义的特许城市人士谈过的、群岛般的不同政府：然后有选择，谁在哪里运作得最有效，人们在哪里最幸福。某种意义上，这就是群岛的乌托邦。

某种程度上是在把那个再造一遍。那个愿景有它值得推荐的地方，也有会出错的地方，错在你没想象到的方面。它是一个有趣的、在某些方面有说服力的愿景，可也会有你没想象到的出错。第二种环也喜欢。可整件事必须是第一、第二、第三种环的某种混合，是比例问题。那必须是答案。

## 后人写这段历史时，最容易漏掉什么

若将来有人写出这个时代相当于《原子弹秘史》的那本书，历史记录里最难被他们拣出来、他们最可能错过的是什么？

几件事。一是在这条指数的每一个时刻，它外面的世界不理解它到了什么程度。历史里常有这种偏差：任何真正发生了的事，事后看起来都不可避免。人们回头看时，会很难把自己放进那些真正在对这件事下注的人的位置。这件事的发生并不是不可避免的。我们有这些论证，关于缩放的论证，关于持续学习会被解决的论证。我们中的一些人在自己脑子里给这件事很高的概率，可我们外面有一个世界，完全没有按这个在行动。它的怪异。不幸的是，还有它的封闭。若我们离它发生还有一年或两年，街上的普通人毫无概念。试图改变的事情之一就是这个：用那些备忘录，去和政策制定者谈。不知道。认为这本身就是一件疯狂的事。

最后，这一点大概适用于几乎所有危机的历史时刻：它绝对地有多快，一切如何同时发生。于是你也许以为是被小心计算过的决定，实际上你得做那个决定，然后同一天还得再做另外三十个，因为它发生得太快。你甚至不知道哪些决定后来会是后果重大的。于是一份担心，虽然它也是对正在发生的事的一种洞察：某个非常关键的决定，会是这样的——有人走进办公室，说，你有两分钟。我们该做 A 还是 B。某人递来一份随便的、半页的备忘录，说该做 A 还是 B。然后说，不知道，我得吃午饭，做 B 吧。而那后来成了有史以来后果最重大的一件事。

## 一个还能写长文的 CEO，是怎么把公司拢住的

科技公司的 CEO 通常不会每隔几个月写一篇五十页的备忘录。看起来他把自己的角色、以及身边这家公司，建成了能容纳这种更偏智识的 CEO 角色。这是怎么构造的？是不是就离开几周，然后告诉公司：这是备忘录，我们这么做？内部据说也写很多。

这一篇特别的，是寒假里写的。当时有时间，可真正找到时间把它写出来并不容易。实际上用一种更宽的方式想这件事。它和公司的文化有关。

大概三分之一、也许 40% 的时间，花在确保 Anthropic 的文化是好的。公司变大之后，更难直接扎进模型的训练、模型的发布、产品的建造。2500 人。有某些直觉，可要扎进每一个细节非常难。尽可能试，可一件杠杆非常高的事，是确保 Anthropic 是一个好的工作场所，人们喜欢在那里工作，每个人把自己当成团队成员，每个人一起工作而不是彼此对着干。

别的一些 AI 公司长大的过程中——不点名——我们开始看到失谐，人们彼此争斗。甚至从一开始就有很多这种事，可它变得更糟。我们即便不完美，也extraordinarily 好地把公司拢在一起，让每个人感到使命，感到我们对使命是真诚的，感到每个人相信那里的每一个人都在为正确的理由工作，我们是一个团队，人们不是在试图以别人的代价往上爬，或者在背后捅刀。这在有些别的地方可以发生得很多。

怎么让它成为事实？很多事。是他本人，是丹妮拉——她管公司的日常——是联合创始人，是我们雇的其他人，是我们试图创造的环境。可文化里重要的一件，是他本人，以及其他领导者，必须把公司是关于什么的、它为什么在做它在做的事、它的战略是什么、它的价值是什么、它的使命是什么、它代表什么，说清楚。到了 2500 人，你不能一个一个地说。你得写，或者你得对整个公司说。

这就是为什么每两周站到整个公司面前，讲一个小时。并不是在内部写文章。做两件事。

一件叫 DVQ，Dario Vision Quest，达里奥的远见追寻。不是他起的名。名字是它自己得到的。试图反对过这个名字，因为它听起来像是要去抽佩奥特之类。可名字就这么粘住了。每两周站到公司面前，有一份三四页的文件，把三四件不同的题目讲一遍：内部在发生什么，我们在做的模型，产品，外部行业，整个世界里和 AI 有关的事，以及一般的地缘政治。某种混合。非常非常诚实地讲。就说：这是我在想的，这是 Anthropic 的领导层在想的。然后回答问题。这种直接的连接有很多价值，是事情传过六层之后很难得到的。公司的很大一部分会来，要么当面，要么线上。这意味着你可以沟通很多。

另一件，是在 Slack 里有一个频道，写很多东西，评论很多。常常是回应在公司里看到的事，人们问的问题，或者内部调查里人们担心的事，然后把它们写出来。对这些非常诚实，说得很直接。要点是得到一种声誉：把正在发生的真相告诉公司。把事情叫做它们所是的那样，承认问题，避开那种公司腔，那种防御性的沟通——在公开场合常常必要，因为世界很大，充满不怀好意地解读事情的人。可若你有一家你信任的人组成的公司，而我们试图雇我们信任的人，那你就可以完全不过滤。

认为这是公司的一种巨大力量。它让这里成为更好的工作场所。它让人们大于部分之和。它提高我们完成使命的可能，因为每个人对使命在同一页上，每个人在辩论和讨论怎样最好地完成使命。

没有一份对外的「达里奥远见追寻」，就有了这场访谈。它有一点像那个。感谢这场对谈。
