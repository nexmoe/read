Thought for 78 seconds

“什么有用就学什么”站不住。它只是“有用即真理”在认识论上的投射；这想法太顺，不反思就很难改。作者认定：在AI时代，它是完全不靠谱的认识原则。

这个原则有三个BUG：

- 人判断不了什么叫“有用”。
- 人类已有的知识并不完备。
- “怎样使用知识”本身也是知识，人同样搞不定。

本集用“学历贬值”这个人人相关的公共问题，让人碰到这三个困难。同时预热下一层批判：“实践出真知”和“学以致用”认知结构很近，却更顽固。它对应毛泽东1937年的知行合一（感性认识与理性认识、实践—认识—再实践—再认识、螺旋式上升），已变成常识，更难反思。本集只是正式挑战前的预热。

作者放了五组学历贬值材料，每组都问：我们为什么爱看？它对你到底有用还是没用？答案都是：既有用，又没用。

- **日本“就职冰河”**：泡沫破裂后，名校文凭迅速失效。有用在于补了一段未知历史；没用在于对策近乎废话，把“把资源投到能产生收益的地方”这类目标说成方法，却不回答什么未来有价值、何时坚持、何时止损。和“坚持长期主义”“实现共同富裕”一样，只讲应当、不讲如何，语用信息增益极低。
- **故事化演绎**（中专曾够安身、如今送外卖、陌生人拼床）：有用在于把零散经验串成社会图景，并用“时代困境”做解释和情绪辩护——不是废物，只是赶上台。没用在于故事感人≠可靠解释；真实经验与艺术加工分不清；个别事件代表不了社会，也说不清学历为何贬值、该如何应对。它给的是经验、故事和情绪，不是可检验的因果。
- **校招现场采访**：爱看，是因为朴素认识论迷信眼见为实。有用在于给“企业看重985、985本科优于普通硕士、实习重要”提供现场证言，强化原有判断。没用在于这些本来就知道，新增认识很少，主要是确认，样本也未必有代表性。
- **高薪招高中生**（硅谷AI公司、腾讯青科实训营、吉利面向高中生的计划）：有用在于说明“高中—大学—企业”不是唯一路径。没用在于知道有这条路，不等于知道自己走不走得了——选拔、培训、晋升、是否符合条件都没回答；已毕业或已工作的人更用不上。新闻只告诉发生了什么，不告诉该怎么办。
- **周鸿祎引杰森·泡茨《AI之后的大学》**：专家权威加学术权威，制造可信感。观点是：AI让作业失去区分度，削弱了大学对学生能力的认证，所以大学应从“教答案”转向“练能力”。这值得讨论，但对教育从业者并不新，对个人也没有可操作的方法。

贯穿五组材料的一点是：一件东西“有没有用”，取决于你原先知道多少、你处在什么位置，以及你要的是新信息、确认、情绪，还是可检验的解释和可执行的方法。看起来有用的内容，常常只是把目标冒充成方法，或只增加一点见识和情绪，并不告诉你未来什么有价值、自己该怎么做。
